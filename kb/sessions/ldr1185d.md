# Plugins and engines: Extending GitHub Copilot live

**Thu Oct 29 2026, 12:25 PM–12:40 PM PDT** · [Silent Disco Demos](../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [David O'Regan](../people/david-o-regan.md)

Developers know agents exist, but many haven’t built on the agent platform themselves. In this fast-paced demo, see how a custom agent plugin is built from scratch, connected to the engine layer, and deployed to a live repository in just 15 minutes. You'll learn how plugins, skills, hooks, and MCP servers work together and know exactly how to extend the platform for your own workflows.

- **Type:** Product Demo
- **Track:** Build software, not code, Lead through what's next
- **Level:** Level 200: Intermediate
- **Topics:** Productivity, Platform engineering, Custom integrations and APIs, AI: Agents, AI: MCP and other integrations
- **GitHub products:** Actions, GitHub Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Startups, Educators & Students
- **Mentions:** [GitHub Copilot](../software/github-copilot.yaml), [Model Context Protocol](../software/model-context-protocol.yaml)
