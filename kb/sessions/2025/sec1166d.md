# Monorepos! Scanning your projects at scale with CodeQL

**Tue Oct 28 2025, 2:25 PM–2:40 PM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Sean Clayton](../../people/sean-clayton.md)

In this 15-minute demonstration, you'll learn how to secure monorepos at scale with GitHub Advanced Security (GHAS) and CodeQL. You'll see a live walkthrough of parallel analysis and language-specific CodeQL tuning for large repositories that accelerates workflow performance. By the end of the demo, you'll know how to configure CodeQL in a monorepo and apply targeted optimizations to streamline your security workflows.

- **Type:** Product Demo
- **Track:** Secure
- **Level:** Level 300: Advanced
- **Topics:** Automated Infrastructure Deployment, Continuous Integration + Continuous Deployment (CI/CD), DevOps and DevSecOps, Monitoring and observability, Open source, Shell programming (Bash, PowerShell, etc.), Tech debt and security debt
- **GitHub products:** Actions, GitHub Advanced Security, GitHub Code Security, GitHub Enterprise Cloud
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Security Professional, Startups, Security Leadership, Educators & Students
- **Mentions:** [CodeQL](../../software/codeql.yaml), [GitHub Advanced Security](../../software/github-advanced-security.yaml)
