# AI-powered API development: From design to deploy in minutes

**Tue Oct 28 2025, 4:10 PM–4:25 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Talia Kohan](../../people/talia-kohan.md)

**Hosted by:** [Postman](../../organizations/postman.md)

Every developer knows the handoff tax between ideas and production. You define the API. You write the code. You open a PR. Then you wait on reviews, tests, and pipelines. What if AI could do most of that for you? In this session, we’ll connect the GitHub MCP Server to Postman’s Agent Mode, an AI-native assistant right within Postman. We’ll show how agents can automate real development tasks from generating code and creating pull requests to wiring up CI/CD with GitHub Actions. You’ll see how you can turn everyday GitHub workflows into fast, automated feedback loops that are secure, observable, and human-approved.

- **Type:** Product Demo
- **Track:** Build, Automate
- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models)
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer
- **Mentions:** [GitHub MCP Server](../../software/github-mcp-server.yaml), [GitHub Actions](../../software/github-actions.yaml)
