# Better conversational agents, less grind — powered by GitHub and ElevenLabs

**Wed Oct 29 2025, 12:20 PM–12:35 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Thor Schaeff](../../people/thor-schaeff.md)

Building conversational agents requires fast iteration, tight feedback loops, and reliable deployment pipelines. In this session, you'll see a practical workflow that combines GitHub Actions, Copilot coding agents, and the ElevenLabs Agents CLI to streamline how conversational AI agents can be developed and deployed with ease. 

Attendees will explore how issues can be assigned to Copilot, automatically turned into pull requests, and seamlessly deployed through Actions to update a production conversational agent. This demo highlights how GitHub can help accelerate iteration cycles, reduce manual overhead, and enable teams to ship better conversational agent experiences faster.
