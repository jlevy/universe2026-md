# Developing highly scalable GitHub Actions workflows with dynamic matrices

**Wed Oct 29 2025, 1:00 PM–1:15 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Thomas Bissell](../../people/thomas-bissell.md)

Looking to scale your CI/CD pipelines without adding complexity? In this session, you’ll learn how to build flexible, scalable workflows in GitHub Actions using dynamic matrices and GitHub variables. We'll walk through practical techniques that enable adaptable CI/CD pipelines, allowing teams to efficiently manage diverse project requirements. You'll learn how these strategies drive consistency and scalability, empowering your team to design robust pipelines.

- **Type:** Product Demo
- **Track:** Build, Automate
- **Level:** Level 300: Advanced
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), Containerized applications, DevOps and DevSecOps, Kubernetes
- **GitHub products:** Actions, GitHub Secret Protection
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Startups
- **Mentions:** [GitHub Actions](../../software/github-actions.yaml)
