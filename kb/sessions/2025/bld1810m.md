# Build apps & agents that scale with VS Code, GitHub Copilot, and Agent Framework

**Tue Oct 28 2025, 12:50 PM–1:20 PM PDT** · [Main Stage](../../rooms/main-stage-festival-pavilion.yaml)

**Speakers:** [Amanda Silver](../../people/amanda-silver.md), [Rong Lu](../../people/rong-lu.md), [Shayne Boyer](../../people/shayne-boyer.md)

In this demo-driven session, see how VS Code and the AI Toolkit turn GitHub Copilot into your AI workbench—where chat, tools, and agents adapt to your flow. We’ll use Spec Kit to go from spec to working code, then build multi‑agent workflows with the open‑source Agent Framework and deploy to Azure AI Foundry with observability, tracing, and safety built in. From first commit to production, you'll learn patterns to ship secure, scalable intelligent apps and multi‑agent workflows.

- **Type:** Main Stage
- **Track:** Build, Secure, Automate
- **Level:** Level 100: Introductory
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Continuous Integration + Continuous Deployment (CI/CD), Software Engineering, Code quality, review, and completion
- **GitHub products:** GitHub Copilot, VS Code
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Security Professional, Startups, Security Leadership, Educators & Students
- **Mentions:** [Visual Studio Code](../../software/vs-code.yaml), [GitHub Copilot](../../software/github-copilot.yaml), [Spec Kit](../../software/spec-kit.yaml), [Microsoft Azure](../../software/azure.yaml)
