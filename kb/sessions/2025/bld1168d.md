# Extending AI Agents: A live demo of the GitHub MCP Server

**Wed Oct 29 2025, 12:00 PM–12:15 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Sam Morrow](../../people/sam-morrow.md), [Toby Padilla](../../people/toby-padilla.md)

Discover the power of agent extensibility with a live demonstration of the GitHub MCP Server. This demo will showcase how to set up Copilot agent mode to seamlessly interact with GitHub directly from VS Code. We'll highlight key MCP tools, effective prompt engineering, and the agent-to-agent capabilities that unlock powerful multi-step workflows through natural language. See firsthand how the GitHub MCP Server redefines collaboration between humans, AI and GitHub.

- **Type:** Product Demo
- **Track:** Build
- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Open source, IDE Integration
- **GitHub products:** GitHub Copilot, VS Code
- **Audience:** Enterprise - Developer, Open Source Developer or Maintainer
- **Mentions:** [GitHub MCP Server](../../software/github-mcp-server.yaml), [GitHub Copilot](../../software/github-copilot.yaml), [Visual Studio Code](../../software/vs-code.yaml), [Model Context Protocol](../../software/model-context-protocol.yaml)
