# From pull request to production: Crafting secure CI/CD with GitHub Actions

**Tue Oct 28 2025, 2:30 PM–4:00 PM PDT** · [Workshops](../../rooms/workshops-gateway-pavilion-level-1.yaml)

**Speakers:** [Kate Catlin](../../people/kate-catlin.md) (facilitator), [Daniel Redman](../../people/daniel-redman.md) (facilitator), [Ken Muse](../../people/ken-muse.md) (facilitator)

From the Codecov Bash Uploader and IAmRoot exploits to compromised Actions, the threat landscape is evolving rapidly — as attackers increasingly target your CI/CD processes, not just your applications.

In this workshop, you’ll learn how to design a secure, production‑ready CI/CD foundation on GitHub Actions that protects your pipeline and deploys without long‑lived secrets. You'll explore techniques for securing your supply chain, implementing least privilege, enforcing guardrails, and eliminating secrets from your deployments. Discover strategies used by top companies to build trust into their delivery pipelines and ship faster with less risk.

- **Type:** Workshop
- **Track:** Secure, Automate
- **Level:** Level 300: Advanced
- **Topics:** Agile practices, Continuous Integration + Continuous Deployment (CI/CD), DevOps and DevSecOps, Security (RASP, supply chain, threat modeling, vulnerability detection), Governance and compliance
- **GitHub products:** Actions, GitHub Advanced Security, Dependabot, GitHub Secret Protection, GitHub Code Security
- **Audience:** Enterprise - Developer, Open Source Developer or Maintainer, Security Professional
- **Mentions:** [GitHub Actions](../../software/github-actions.yaml)
