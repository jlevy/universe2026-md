# Building GitHub with Copilot: How our engineers multiply their impact and reliably ship features

**Tue Oct 28 2025, 11:30 AM–12:10 PM PDT** · [BATS Theatre](../../rooms/bats-theatre-fort-mason-building-b.yaml)

**Speakers:** [Bassem Dghaidi](../../people/bassem-dghaidi.md)

As a software engineer on the GitHub Actions core team, Bassem was an early adopter of GitHub Copilot. He quickly evolved his workflow to integrate Copilot because of its clear value add. Two years later, Copilot is an integral part of how he writes and ships features every day at GitHub. From automating coding tasks to security reviews, deep dives, in-depth analyses, and discovering idiomatic ways to refactor a piece of code, Copilot has become what he describes as his "second brain."  In this talk, Bassem will share some of his main use cases, and how he uses Copilot to accelerate his workflows, learn, and bring value to his team.

- **Type:** Breakout Session
- **Track:** Build, Automate
- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), DevOps and DevSecOps, Git and code management techniques, Open source, Pair programming, Testing and related practices, Collaboration, Tech debt and security debt, Code quality, review, and completion, IDE Integration
- **GitHub products:** Actions, GitHub Copilot, VS Code
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Security Professional, Startups, Security Leadership, Educators & Students
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml), [GitHub Actions](../../software/github-actions.yaml)
