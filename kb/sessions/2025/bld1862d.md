# Supercharge your enterprise planning with GitHub Issues, Projects, and Copilot

**Tue Oct 28 2025, 4:30 PM–4:45 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Evi Liu](../../people/evi-liu.md)

See how these new features make GitHub’s planning tools enterprise-ready, and get a first look at how we’re reimagining project management with Copilot in the loop.
