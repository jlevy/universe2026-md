# Enterprise development roundtable: Bridging cloud and private IT strategies

**Tue Oct 28 2025, 11:50 AM–12:50 PM PDT** · [Discussions Lounge](../../rooms/discussions-lounge-fort-mason-building-d.yaml)

**Speakers:** [Nicole Fagen](../../people/nicole-fagen.md) (facilitator)

Large enterprises typically have complex application portfolios spanning public and private clouds, distributed systems, and even mainframes. Standardizing development is difficult because teams are organized by line of business, by platform, or both — each with its own practices and tools — but new solutions create an opportunity to reevaluate how applications are built.

In this interactive roundtable discussion, we’ll explore how tools like GitHub Copilot and GitHub Codespaces can help reimagine software development in large enterprises.

- **Type:** Discussions Lounge
- **Track:** Build, Automate
- **Level:** Level 200: Intermediate
- **Topics:** Agile practices, AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Automated Infrastructure Deployment, Cloud-native development, Continuous Integration + Continuous Deployment (CI/CD), DevOps and DevSecOps, Git and code management techniques, Infrastructure as code, Monitoring and observability, Open source, Pair programming, Testing and related practices, Collaboration, Productivity, Platform engineering, Code quality, review, and completion, Custom integrations and APIs, Governance and compliance, IDE Integration
- **GitHub products:** Actions, Codespaces, GitHub Copilot, GitHub Copilot Workspace, GitHub Enterprise Cloud, GitHub Enterprise Server, Marketplace, VS Code, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml), [GitHub Codespaces](../../software/codespaces.yaml)
