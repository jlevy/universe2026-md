# Build, automate, accelerate: Level up your developer experience with Rovo Dev Agent

**Wed Oct 29 2025, 12:35 PM–1:35 PM PDT** · [Sandbox](../../rooms/sandbox-firehouse.yaml)

**Speakers:** [Jovana Dunisijevic](../../people/jovana-dunisijevic.md) (facilitator)

**Hosted by:** [Atlassian](../../organizations/atlassian.md)

Discover how Atlassian’s new AI-powered Rovo Dev Agent is transforming the software development lifecycle (SDLC) from planning to production.

In this interactive session, explore real-world use cases where Rovo Dev Agent streamlines development workflows, including practical examples of how integrating GitHub and Atlassian tools delivers tangible benefits for teams. Get ample practice with Rovo Dev Agent in a guided sandbox environment, as we walk through how our intelligent developer agent supports various stages of the SDLC, from planning, writing and reviewing code, to deployment.

- **Type:** Sandbox Session
- **Track:** Build, Automate
- **Level:** Level 200: Intermediate
- **Topics:** Agile practices, AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), DevOps and DevSecOps, Collaboration, Productivity, Code quality, review, and completion
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Educators & Students
