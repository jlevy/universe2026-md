# Prompts, patterns, and power tools for your AI-powered OSPO toolkit

**Wed Oct 29 2025, 12:15 PM–12:55 PM PDT** · [BATS Theatre](../../rooms/bats-theatre-fort-mason-building-b.yaml)

**Speakers:** [Ashley Wolf](../../people/ashley-wolf.md) (moderator), [Oscar Valenzuela](../../people/oscar-valenzuela.md) (panelist), [Natali Vlatko](../../people/natali-vlatko.md) (panelist), [Alyssa Wright](../../people/alyssa-wright.md) (panelist)

What does it look like when an open source program office (OSPO) brings AI into their day-to-day work? In this panel, OSPO leaders from GitHub, Cisco, Amazon, and Bloomberg will share how they’re using AI workflows to automate open source tasks like license and security reviews, sponsorship discovery, and community analysis. We’ll also highlight a public talk openly, develop openly (TODO) group hosted repository of prompts, workflows, and tools built with contributions from OSPOs. Attendees will hear real examples from across the industry and leave with ready-to-use ideas to try in their own programs — no machine learning experience required.

- **Type:** Panel Discussion
- **Track:** Build, Automate
- **Level:** Level 100: Introductory
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Open source, Collaboration
- **GitHub products:** Actions, GitHub Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer
- **Mentions:** [Cisco](../../organizations/cisco.md), [Amazon](../../organizations/amazon.md), [Bloomberg LP](../../organizations/bloomberg-lp.md)
