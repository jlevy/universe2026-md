# Speed meets security: CI/CD pipelines with GitHub, Octopus, and AI

**Tue Oct 28 2025, 12:30 PM–12:45 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Bob Walker](../../people/bob-walker.md)

**Hosted by:** [Octopus Deploy](../../organizations/octopus-deploy.md)

In this live demonstration, you’ll see how to build CI/CD pipelines that are fast, secure, and compliant using GitHub and Octopus Deploy. Learn best practices for generating SBOMs, scanning for vulnerabilities, and verifying provenance and attestations—all without slowing down delivery. You’ll also see how AI helps developers self-remediate deployment or verification issues in minutes, not hours. With these three pillars, you’ll ship software faster—and deploy with confidence.

- **Type:** Product Demo
- **Track:** Secure, Automate
- **Level:** Level 200: Intermediate
- **Topics:** Agile practices, AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Continuous Integration + Continuous Deployment (CI/CD), DevOps and DevSecOps, Security (RASP, supply chain, threat modeling, vulnerability detection), Governance and compliance
- **GitHub products:** Actions, GitHub Advanced Security, Dependabot, GitHub Code Security, VS Code
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Security Professional, Security Leadership
