# CodeQL: Choose Your Own (Security) Adventure

**Wed Oct 29 2025, 2:15 PM–2:55 PM PDT** · [Cowell Theater](../../rooms/cowell-theater-gateway-pavilion-level-1.yaml)

**Speakers:** [Viktor Lindström](../../people/viktor-lindstrom.md), [Anja Loether](../../people/anja-loether.md)

Static Application Security Testing (SAST) is often dismissed as just another code scanning tool — but when you take control, it can do so much more. In this session, GitHub and WirelessCar experts will show you how to go beyond the basics by customizing SAST rules to fit your applications and security priorities. You’ll learn why writing your own rules matters, how to do it effectively, and how to boost your results even further using targeted security campaigns. Walk away with practical tips to help you unlock deeper insights, strengthen your defenses, and take back control of your application security.

- **Type:** Breakout Session
- **Track:** Secure
- **Level:** Level 200: Intermediate
- **Topics:** DevOps and DevSecOps, Security (RASP, supply chain, threat modeling, vulnerability detection), Code quality, review, and completion
- **GitHub products:** GitHub Advanced Security
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Security Professional, Startups, Security Leadership, Educators & Students
- **Mentions:** [CodeQL](../../software/codeql.yaml), [WirelessCar](../../organizations/wirelesscar.md)
