# Ship & Tell: AMD

**Tue Oct 28 2025, 12:10 PM–12:35 PM PDT** · [GitHub Central](../../rooms/github-central-festival-pavilion.yaml)

**Speakers:** [Alexander Androncik](../../people/alexander-androncik.md), [Anna Safonov](../../people/anna-safonov.md), [Andrew Ross](../../people/andrew-ross.md)

AMD standardized on GitHub Enterprise to bring hardware and software engineering together at scale, fueling innovation with GitHub Copilot and Agent Mode, and strengthening security with GitHub Advanced Security. In this interactive Q&A, AMD’s development team will share how they’re leading change across a global engineering organization, from adopting agentic AI to building securely and innovating faster with GitHub.

Come ready with your questions and stay tuned for AMD’s full customer video, coming soon.

- **Type:** Ship & Tell
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Security (RASP, supply chain, threat modeling, vulnerability detection)
- **GitHub products:** GitHub Advanced Security, GitHub Copilot
- **Audience:** Enterprise - Engineering Leadership, Security Professional, Security Leadership
- **Mentions:** [AMD](../../organizations/amd.md), [GitHub Copilot](../../software/github-copilot.yaml), [GitHub Advanced Security](../../software/github-advanced-security.yaml)
