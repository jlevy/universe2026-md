# Co-op with GitHub Copilot: Building games the smarter way

**Wed Oct 29 2025, 3:20 PM–4:20 PM PDT** · [Sandbox](../../rooms/sandbox-firehouse.yaml)

**Speakers:** [Harshita Jain](../../people/harshita-jain.md) (facilitator)

What if your AI pair programmer could help you polish your player’s jump mechanics, time moving platforms, outsmart bot enemies, and architect gameplay logic? In this talk, you’ll hear how GitHub Copilot helped shape the development of a feature-rich 2D platformer in Unity - offering support on everything from in-game event handling to game state management to bug-prone edge cases. 

Whether you build games or distributed systems, this session will show you how GitHub Copilot can be more than just a code generator - it can be your thinking partner in chaos.
