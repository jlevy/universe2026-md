# Sentry, GitHub, and the era of the “Just Ship It” workflow

**Tue Oct 28 2025, 11:50 AM–12:05 PM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Cody De Arkland](../../people/cody-de-arkland.md)

**Hosted by:** [Sentry](../../organizations/sentry.md)

Workflows aren’t one-size-fits-all — especially now, when AI lets you build and customize the toolchain of your over-engineered dreams. With Sentry and GitHub, you get the flexibility to build how you want and the visibility to fix whatever breaks. 

In this interactive session, you'll see how bringing Sentry and GitHub Copilot together gives you the next generation of AI-powered debugging. You'll see how tools like Sentry's MCP server can use Seer to bring together all the context from logs, traces, stack traces, and errors to debug and fix the issue locally with GitHub Copilot, or how you can go hands-off and use Seer to automatically create pull requests in GitHub to fix issues automatically. 

Sentry and GitHub give you the best workflow for debugging issues, and fixing bugs, anywhere your workflow lives.
