# How to vibe code responsibly (with a little help from MCPs)

**Wed Oct 29 2025, 4:00 PM–4:15 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Rizel Scarlett](../../people/rizel-scarlett.md)

The year of the agent ushered in vibe coding — asking an AI agent to build and going with the flow. But too often we’re Icarus with a keyboard and flying too close to the sun. Agents can overwrite files, expose API keys, or hallucinate broken flows. In this talk, Rizel will explain how the Model Context Protocol (MCP) adds structure and context, helping developers avoid these pitfalls. Using GitHub’s MCP server, she will demo safer prompting, better observability, and how to keep the vibes high and the bugs low.

- **Type:** Product Demo
- **Track:** Build
- **Level:** Level 100: Introductory
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Open source, Productivity
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Security Professional, Startups, Security Leadership, Educators & Students
- **Mentions:** [Model Context Protocol](../../software/model-context-protocol.yaml)
