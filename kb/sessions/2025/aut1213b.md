# Scaling identity: How to migrate a large enterprise to Enterprise Managed Users (EMU)

**Tue Oct 28 2025, 12:30 PM–1:10 PM PDT** · [BATS Theatre](../../rooms/bats-theatre-fort-mason-building-b.yaml)

**Speakers:** [Erik Englund](../../people/erik-englund.md), [JD Weeks](../../people/jd-weeks.md), [Christian Oestreich](../../people/christian-oestreich.md)

Learn how WEX migrated thousands of developers to GitHub Enterprise Managed Users (EMU), integrating Azure Active Directory, SCIM provisioning, and automated repository access management. 

During the session, you'll also discover how WEX minimized disruption while building a secure, automated foundation for developer productivity at scale, resulting in measurable time and cost savings, reduced manual support, and an improved security posture. The team will share hard-earned lessons on scaling identity, cleaning up legacy access, and creating audit-ready workflows that streamline compliance and reduce operational overhead.

- **Type:** Breakout Session
- **Track:** Secure, Automate
- **Level:** Level 300: Advanced
- **Topics:** Tech debt and security debt, Migration strategies
- **GitHub products:** GitHub Enterprise Cloud
- **Audience:** Security Professional, Security Leadership
- **Mentions:** [WEX](../../organizations/wex.md), [Microsoft Azure](../../software/azure.yaml)
