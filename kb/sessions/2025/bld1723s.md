# Upgrade with confidence: Migrate your Legacy PayPal integrations with AI

**Tue Oct 28 2025, 1:10 PM–2:10 PM PDT** · [Sandbox](../../rooms/sandbox-firehouse.yaml)

**Speakers:** [Janani Chandiran](../../people/janani-chandiran.md) (facilitator), [Navinkumar Patil](../../people/navinkumar-patil.md) (facilitator)

PayPal’s AI Assistant accelerates modernization by guiding developers through upgrades from legacy products to the latest REST APIs and SDKs. It creates migration plans, maps code, and provides testing guidance — all powered by AI.

This session highlights how the assistant simplifies the JS v5 to v6 upgrade. In the workshop, attendees will get a chance to try the assistant — featuring the recently launched JS v6 SDK — and see how AI makes migrations faster, smarter, and more impactful.

- **Type:** Sandbox Session
- **Track:** Build, Automate
- **Level:** Level 200: Intermediate
- **Topics:** Custom integrations and APIs, Migration strategies
- **GitHub products:** GitHub Copilot, VS Code
- **Audience:** Enterprise - Developer, Open Source Developer or Maintainer
- **Mentions:** [PayPal](../../organizations/paypal.md)
