**Tue Oct 28 2025, 4:05 PM–4:20 PM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Ben Dang](../../people/ben-dang.md), [Harley Vanselow](../../people/harley-vanselow.md)

In this session, you'll discover how Okta's team swapped the security risk for a developer-friendly interface that offers time-limited repository access. Learn about their custom GitHub app and the CLI tool that made this security enhancement seamless.
