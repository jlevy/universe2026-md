# From pair to peer: The next evolution of Copilot code review

**Tue Oct 28 2025, 2:45 PM–3:00 PM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Elle Shwer](../../people/elle-shwer.md)

This session explores how GitHub Copilot is transforming the entire pull request experience — not just by reviewing code, but by acting as a full-fledged agent that helps developers write, refine, and ship high-quality changes faster. You'll get a chance to walk through the journey from public preview to GA, hear what the GitHub team has learned from customers, and discover what’s next in the product queue. From generating pull request summaries to surfacing repo-aware feedback, Copilot is changing how teams use GitHub to collaborate and merge secure code with confidence.

- **Level:** Level 100: Introductory
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Code quality, review, and completion
- **GitHub products:** GitHub Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Startups
