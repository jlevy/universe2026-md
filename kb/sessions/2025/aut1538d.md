# Stop guessing, start showing: Copilot's impact on engineering efficiency

**Tue Oct 28 2025, 10:50 AM–11:05 AM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Andrew Lau](../../people/andrew-lau.md)

**Hosted by:** [Jellyfish](../../organizations/jellyfish.md)

GitHub Copilot is now a standard tool in every developer's toolbox, but here's the burning question: How do we demonstrate the impact it's having in engineering productivity? In this session, we'll dive into the data from Copilot and show you how to connect it to key engineering metrics. We'll figure out who's using it, and where we're seeing real boosts in engineering velocity, throughput, cycle time, and more.

- **Type:** Product Demo
- **Track:** Build, Automate
- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Continuous Integration + Continuous Deployment (CI/CD), Productivity
- **GitHub products:** GitHub Copilot
- **Audience:** Enterprise - Engineering Leadership
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml)
