# Unlocking new workflows with Tailscale and GitHub Actions

**Wed Oct 29 2025, 3:30 PM–3:45 PM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Lee Briggs](../../people/lee-briggs.md)

**Hosted by:** [Tailscale](../../organizations/tailscale.md)

Discover how combining Tailscale’s secure networking with GitHub Actions opens up new possibilities for automation and CI/CD. In this session, you’ll explore how ephemeral, secure networks enable private service testing, multi-cloud deployments, and workflows that were previously impractical — or even impossible — without complex networking. You’ll also take home practical techniques for building faster, safer pipelines by bridging GitHub’s developer platform with Tailscale’s connectivity layer.

- **Type:** Product Demo
- **Track:** Secure, Automate
- **Level:** Level 200: Intermediate
- **Topics:** Automated Infrastructure Deployment, Continuous Integration + Continuous Deployment (CI/CD), DevOps and DevSecOps, Security (RASP, supply chain, threat modeling, vulnerability detection), Platform engineering
- **GitHub products:** Actions
- **Audience:** Enterprise - Developer, Open Source Developer or Maintainer, Security Professional, Startups
- **Mentions:** [GitHub Actions](../../software/github-actions.yaml)
