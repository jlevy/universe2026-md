# How to seamlessly build apps with GitHub Copilot and AI agents

**Wed Oct 29 2025, 1:20 PM–1:35 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Shayne Boyer](../../people/shayne-boyer.md)

See how GitHub Copilot, MCP servers, and agents simplify app development and deployment — right from VS Code or GitHub.com. 

In this fast-paced demo session, you’ll learn how to code, deploy, and automate tasks with just a few prompts. Watch Copilot assign issues, work asynchronously, and review pull requests — all with secure, managed access to your cloud resources. Whether you're new to cloud dev or looking to boost productivity, this session shows how effortless it can be.

- **GitHub products:** GitHub Copilot, VS Code, Projects and Issues
- **Audience:** Enterprise - Developer, Open Source Developer or Maintainer, Startups, Educators & Students
