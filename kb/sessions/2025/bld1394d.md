# Using GitHub Copilot beyond the editor to transform workflows

**Tue Oct 28 2025, 2:50 PM–3:05 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Tobias Ahlin](../../people/tobias-ahlin.md), [Ellie Bennett](../../people/ellie-bennett.md)

Tired of juggling tabs, re-explaining logic, and losing time to context switching? GitHub Copilot is designed to help address these challenges. Beyond writing code, Copilot now helps you manage issues, answer repository questions, and automate repetitive tasks — all through natural language. 

In this session, we’ll explore how Copilot is being designed to help developers stay focused and productive, and share a preview of upcoming capabilities that aim to simplify common tasks.

- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Security Professional, Startups, Educators & Students
