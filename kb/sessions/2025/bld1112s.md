# Build once and teach forever: Scaling developer content creation with GitHub

**Tue Oct 28 2025, 2:30 PM–3:30 PM PDT** · [Sandbox](../../rooms/sandbox-firehouse.yaml)

**Speakers:** [Bree Hall](../../people/bree-hall.md) (facilitator)

Creating technical content is often a repetitive, ad hoc process — one that can quickly become a bottleneck for developer advocates, educators, and open source contributors. That's why this session will introduce a scalable, GitHub-powered system for building, maintaining, and automating technical content workflows using GitHub Copilot, Codespaces, and GitHub Actions. There will be practical scaling tips, common pitfalls to keep in mind (such as AI hallucinations and automation overload), and strategies for adapting the system for solo developers, DevRel teams, and open source projects. By the end, you’ll leave with a ready-to-use system for building and maintaining technical content — one that saves time, reduces duplication, and scales with your needs.

- **Track:** Build, Automate
- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Open source, Collaboration, Productivity, Code quality, review, and completion, Education
- **GitHub products:** Actions, Codespaces, GitHub Copilot, Discussions, VS Code, Projects and Issues
- **Audience:** Enterprise - Developer, Open Source Developer or Maintainer, Educators & Students
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml), [GitHub Codespaces](../../software/codespaces.yaml), [GitHub Actions](../../software/github-actions.yaml)
