# Increasing velocity while lowering risk: Cathay’s Enterprise journey to integrated AI and DevSecOps

**Wed Oct 29 2025, 3:15 PM–3:45 PM PDT** · [Main Stage](../../rooms/main-stage-festival-pavilion.yaml)

**Speakers:** [Rajeev Nair](../../people/rajeev-nair.md), [Naveen Jaisankar](../../people/naveen-jaisankar.md), [Karan M V](../../people/karan-m-v.md)

Cathay is moving beyond standalone tools by integrating GitHub Copilot, GitHub Actions, and GitHub Code Security into developer workflows on GitHub’s platform, boosting productivity, strengthening security, and establishing governance for enterprise-scale adoption.

In this talk, Cathay’s Rajeev Nair and Naveen Jaisankar, partner with GitHub’s Karan M V, to share Cathay’s playbook for integrated AI adoption, from early pilots to scaling AI-powered development across 1,000 developers. They will discuss the cultural and technical challenges they faced, such as alert fatigue, LLM hallucinations, and Shadow AI, as well as the strategies they used to overcome them.

- **Type:** Main Stage
- **Track:** Secure, Automate
- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), DevOps and DevSecOps, Collaboration, Tech debt and security debt, Platform engineering, Code quality, review, and completion, Governance and compliance
- **GitHub products:** Actions, GitHub Advanced Security, GitHub Copilot, Dependabot, GitHub Secret Protection, GitHub Code Security, GitHub Enterprise Cloud, VS Code
- **Audience:** Enterprise - Engineering Leadership, Security Professional, Security Leadership
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml), [GitHub Actions](../../software/github-actions.yaml), [GitHub Code Security](../../software/github-code-security.yaml)
