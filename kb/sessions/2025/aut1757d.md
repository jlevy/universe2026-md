# How enterprises built faster, smarter, and safer with enterprise-grade AI

**Wed Oct 29 2025, 1:40 PM–1:55 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Dimitri Baikrich](../../people/dimitri-baikrich.md)

**Hosted by:** [PALO IT](../../organizations/palo-it.md)

Discover how leading enterprises, like Singapore Airlines, accelerate secure software delivery with PALO IT’s AI-first engineering approach Gen-e2™, powered by GitHub Copilot. Learn how this methodology cuts delivery time in half, boosts build success rates to over 90%, and strengthens quality for regulated industries. The session will also showcase new Gen-e2™ capabilities like MCP and VSCode extensions that enable faster, safer enterprise-grade development.

- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Automated Infrastructure Deployment, Continuous Integration + Continuous Deployment (CI/CD), Containerized applications, Infrastructure as code, Monitoring and observability, Testing and related practices, Collaboration, Productivity, Tech debt and security debt, Code quality, review, and completion, Custom integrations and APIs, Governance and compliance, IDE Integration
- **GitHub products:** GitHub Advanced Security, GitHub Copilot, GitHub Enterprise Cloud, VS Code, GitHub Spark, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Security Leadership
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml), [Model Context Protocol](../../software/model-context-protocol.yaml), [Visual Studio Code](../../software/vs-code.yaml)
