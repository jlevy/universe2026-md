# When Q-day strikes: Securing cryptography at scale with CodeQL and GitHub Copilot

**Tue Oct 28 2025, 10:30 AM–11:30 AM PDT** · [Sandbox](../../rooms/sandbox-firehouse.yaml)

**Speakers:** [Daniel Cuthbert](../../people/daniel-cuthbert.md) (facilitator), [Ben Rodes](../../people/ben-rodes.md) (facilitator), [Nicolas Will](../../people/nicolas-will.md) (facilitator)

Q-Day - the day quantum computers can break classic cryptography - is quickly approaching. In this session, we'll walk through that Y2K-like scenario, showing how CodeQL and GitHub Copilot can identify, analyze, and fix insecure cryptography at enterprise scale. 

We'll start by sharing why cryptographic security and post-quantum readiness should be on every organization's radar. Then, we'll dive into our cryptography security approach, powered by GitHub Copilot and CodeQL, and take you through an interactive enterprise demo on finding and fixing vulnerabilities. You’ll leave with practical insights and next steps to help your organization start securing its cryptography today.

- **Type:** Sandbox Session
- **Track:** Secure
- **Level:** Level 300: Advanced
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Security (RASP, supply chain, threat modeling, vulnerability detection), Tech debt and security debt, Governance and compliance
- **GitHub products:** Actions, GitHub Advanced Security, GitHub Copilot, GitHub Code Security, GitHub Enterprise Cloud, GitHub Enterprise Server, VS Code
- **Audience:** Enterprise - Engineering Leadership, Security Professional, Security Leadership
- **Mentions:** [CodeQL](../../software/codeql.yaml), [GitHub Copilot](../../software/github-copilot.yaml)
