# Integrating with PayPal: From no-code start to AI-guided migrations

**Wed Oct 29 2025, 12:35 PM–12:50 PM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Perumal Palani](../../people/perumal-palani.md)

Merchants starting with PayPal have options that scale with their needs—from no-code payment links and buttons, to low-code SDKs to robust REST and JS integrations. But millions of merchants still run on legacy NVP and SOAP APIs, missing out on the latest capabilities. 

In this demo, you'll explore how PayPal’s AI Migration Assistant—a VS Code extension—together with GitHub Copilot, can transform a legacy NVP/SOAP checkout into a modern REST integration in minutes. Along the way, you'll learn about other upgrade paths the assistant supports, including the brand-new JSv6 SDK.

- **Type:** Product Demo
- **Level:** Level 100: Introductory
- **Topics:** Custom integrations and APIs, Migration strategies
- **GitHub products:** GitHub Copilot, VS Code
- **Audience:** Enterprise - Developer, Open Source Developer or Maintainer
- **Mentions:** [PayPal](../../organizations/paypal.md), [Visual Studio Code](../../software/vs-code.yaml), [GitHub Copilot](../../software/github-copilot.yaml)
