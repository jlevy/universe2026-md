# Pipelines reimagined: Nordstrom’s standardized pipeline and migration with agentic AI

**Wed Oct 29 2025, 12:05 PM–12:35 PM PDT** · [Main Stage](../../rooms/main-stage-festival-pavilion.yaml)

**Speakers:** [William Salazar](../../people/william-salazar.md), [Ella Ordona](../../people/ella-ordona.md), [Anabelle Watt](../../people/anabelle-watt.md)

Nordstrom’s migration from GitLab to GitHub was an opportunity to redesign CI/CD, not just move it. We built a Standard Pipeline on GitHub using reusable workflows, composite actions, and environment-based guardrails so teams can build, test, and ship quickly and consistently. We’ll share the technical decisions behind the design, how our CI/CD philosophy evolved, and how agent-assisted tooling helped translate legacy jobs into GitHub Actions safely and at speed with humans in the loop.

You’ll see how standardized patterns and GitHub-native building blocks such as reusable workflows, composite actions, environments, and rulesets improve reliability and security. These advantages can potentially turn months of conversion work into weeks. You’ll leave with templates, migration tips, and change management practices you can apply to scale modern CI/CD on GitHub across your organization.

- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer
