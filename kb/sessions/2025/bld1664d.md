# Power agentic workflows in your terminal with GitHub Copilot CLI

**Tue Oct 28 2025, 12:10 PM–12:25 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Ryan Hecht](../../people/ryan-hecht.md)

Transform your terminal into an AI-powered development environment with GitHub Copilot CLI, which brings the same runtime that powers GitHub Copilot coding agent directly to your command line. In this demo, discover how you can use Copilot CLI to build, debug, and understand code through natural language interactions. Watch as the team demonstrates real-world terminal-first development workflows invoking a coding agent, while maintaining full transparency and control throughout.
