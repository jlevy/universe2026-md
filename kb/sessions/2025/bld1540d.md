# Aligning code and design intent with Figma and GitHub Copilot

**Wed Oct 29 2025, 12:15 PM–12:30 PM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Jake Albaugh](../../people/jake-albaugh.md)

**Hosted by:** [Figma](../../organizations/figma.md)

Figma’s Dev Mode MCP server allows GitHub Copilot to access both design and codebase context in Figma, helping you write design-aligned UI code faster. This approach becomes even more powerful when your team aligns design patterns across Figma and your codebase using variable and component libraries.

Join Jake Albaugh, developer advocate at Figma, to discover how you can pair the Dev Mode MCP server with GitHub Copilot to improve your agentic workflows and consistently align production code to design intent.
