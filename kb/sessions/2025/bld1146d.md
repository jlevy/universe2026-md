# Dream it. See it. Ship it with GitHub Spark.

**Wed Oct 29 2025, 4:30 PM–4:45 PM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Kelsey Conophy](../../people/kelsey-conophy.md)

With GitHub Spark, you can accelerate the journey from idea to production-ready app, with built-in support for scalable and secure development practices. In this session, you'll learn about Spark's latest capabilities, including updates to the app-building process, an introduction to the Spark SDK, and a deeper dive into Spark runtime. You'll even get a sneak peek at what's coming next.

- **Type:** Product Demo
- **Track:** Build
- **Level:** Level 100: Introductory
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models)
- **GitHub products:** GitHub Spark
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Startups, Educators & Students
