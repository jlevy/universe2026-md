# Agentic DevOps in action: From concepts to capabilities

**Tue Oct 28 2025, 3:50 PM–4:50 PM PDT** · [Discussions Lounge](../../rooms/discussions-lounge-fort-mason-building-d.yaml)

**Speakers:** [Jason Cook](../../people/jason-cook.md) (facilitator), [Suzanne Daniels](../../people/suzanne-daniels.md) (facilitator), [David Sanchez](../../people/david-sanchez.md) (facilitator)

In this expert-led discussion, you'll discover how agentic DevOps is transforming software delivery with AI, automation, and integrated Microsoft-GitHub tooling. You'll explore real-world stories, challenges, and lessons from teams leveraging intelligent, developer-centric workflows. In small groups, dive into themes such as AI in CI/CD, developer experience, security at scale, and operational efficiency. Whether you're starting out or scaling up, come share and learn.

- **Type:** Discussions Lounge
- **Track:** Automate
- **Level:** Level 200: Intermediate
- **Topics:** Agile practices, Automated Infrastructure Deployment, Cloud-native development, Continuous Integration + Continuous Deployment (CI/CD), Data (analytics, management, privacy), DevOps and DevSecOps, Monitoring and observability, Security (RASP, supply chain, threat modeling, vulnerability detection), Collaboration, Productivity, Tech debt and security debt, Platform engineering, Code quality, review, and completion, Custom integrations and APIs, Governance and compliance, Migration strategies
- **GitHub products:** Actions, GitHub Advanced Security, Codespaces, GitHub Copilot, Discussions, Dependabot, GitHub Secret Protection, GitHub Code Security, GitHub Enterprise Cloud, GitHub Enterprise Server, Marketplace, VS Code, GitHub Spark, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Security Professional, Startups, Security Leadership
