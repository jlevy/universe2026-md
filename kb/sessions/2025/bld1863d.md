# Getting what you asked for: Spec-driven development with AI

**Tue Oct 28 2025, 4:25 PM–4:40 PM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Den Delimarsky](../../people/den-delimarsky.md)

Ever asked an AI coding agent to build something, only to get code that technically works but completely misses the mark? You’re not alone.

In this session, you’ll discover Spec Kit, an open source toolkit that changes how you collaborate with AI coding agents. Instead of tossing vague prompts into the void, you’ll learn how to create living specifications that guide AI to deliver exactly what you need.

We’ll show how Spec Kit turns chaotic “just build it” requests into clear, testable roadmaps. You’ll see how it breaks development into four validated phases, embeds your actual requirements, and adds checkpoints to catch issues before they become costly surprises.

Whether you’re using GitHub Copilot, Claude Code, or any other AI agent, you’ll leave knowing how to stay in the driver’s seat—steering, validating, and iterating with confidence instead of cleaning up after the fact.
