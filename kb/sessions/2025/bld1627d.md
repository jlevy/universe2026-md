# Shipping consistent UIs at scale: A distributed micro frontend model that works

**Wed Oct 29 2025, 4:10 PM–4:25 PM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Avanish Pathak](../../people/avanish-pathak.md), [Mark Peterson](../../people/mark-peterson.md)

Large enterprises want fast, consistent web experiences—but often end up with fragmented stacks, duplicated UI logic, and monorepo friction. That's why Docusign built 1FE (“One Frontend”), an open‑source micro frontend platform that enables autonomous teams to ship self‑contained widgets, while a shared runtime, governance layer, and GitHub‑native automation enforce consistency, security, and performance.

In this session, you'll discover how 1FE differs from classic module federation or forced monorepos; how teams hot‑reload local changes against live environments; and how centralized utilities (auth, feature flags, logging, design tokens) accelerate delivery. Expect architecture deep dives, a live workflow demo, real metrics (duplication, onboarding, release time), and a practical adoption playbook.
