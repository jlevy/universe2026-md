# From burnout to breakthrough: Building agentic workflows that save millions

**Wed Oct 29 2025, 12:40 PM–12:55 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Connor Uhlman](../../people/connor-uhlman.md)

Engineering teams are drowning in to-do lists: migrations, dependency upgrades, security patches, and ever-changing internal standards. What if your AI tools could take care of that for you? In this fast-paced demo, see firsthand how Principal Financial Group leveraged GitHub Copilot — and other LLM agents — along with Model Context Protocol (MCP) to orchestrate automated updates across thousands of repositories — saving their team tens of thousands of engineering hours. You'll walk away with practical insights to kickstart your own AI-powered workflows and start enabling happier, more focused engineering teams.

- **Type:** Product Demo
- **Track:** Build, Automate
- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Continuous Integration + Continuous Deployment (CI/CD), DevOps and DevSecOps, Collaboration, Productivity, Tech debt and security debt
- **GitHub products:** Actions, GitHub Copilot, VS Code
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer
- **Mentions:** [Principal Financial Group](../../organizations/principal-financial-group.md), [GitHub Copilot](../../software/github-copilot.yaml), [Model Context Protocol](../../software/model-context-protocol.yaml)
