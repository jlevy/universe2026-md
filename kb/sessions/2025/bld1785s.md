# The multi-core developer: Unlocking productivity with GitHub Copilot coding agent

**Tue Oct 28 2025, 3:50 PM–4:50 PM PDT** · [Sandbox](../../rooms/sandbox-firehouse.yaml)

**Speakers:** [Tim Rogers](../../people/tim-rogers.md) (facilitator), [Jason Etcovitch](../../people/jason-etcovitch.md) (facilitator)

Thanks to the wonders of multi-core processors, computers can do multiple things at once. When it comes to developers, though, we're stuck doing one thing at a time. But Copilot coding agent changes the game. Hand a task to Copilot and it works in the background—preparing a pull request and tagging you for review. This helps developers work more efficiently. Copilot can work on a bug fix while you’re in a meeting, refactor while you work on new features, or even update documentation while you’re making coffee.

This session will start with a short demo showing you how to get started with the agent. Then you'll get advanced tips and best practices, so you can become your team’s resident coding agent expert. Finally, you'll join an interactive lab where you can try Copilot coding agent for yourself and get your questions answered.
