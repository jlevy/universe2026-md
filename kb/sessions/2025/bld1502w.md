# Collaborating with agents in your software development workflow

**Wed Oct 29 2025, 11:15 AM–12:45 PM PDT** · [Workshops](../../rooms/workshops-gateway-pavilion-level-1.yaml)

**Speakers:** [Christopher Harrison](../../people/christopher-harrison.md) (facilitator)

GitHub Copilot's agentic capabilities enhance its ability to act as a peer programmer. From the IDE to the repository, GitHub Copilot can generate code, run tests, and perform tasks, like creating pull requests using Model Context Protocol (MCP). This instructor-led lab will guide you through using agent capabilities on both the client and the server — helping you make the most of AI agents with quick tips to overcome potential pitfalls and plenty of best practices along the way.

- **Type:** Workshop
- **Track:** Build
- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Continuous Integration + Continuous Deployment (CI/CD), Pair programming, Productivity, Code quality, review, and completion, IDE Integration
- **GitHub products:** GitHub Copilot
- **Audience:** Enterprise - Developer, Open Source Developer or Maintainer
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml), [Model Context Protocol](../../software/model-context-protocol.yaml)
