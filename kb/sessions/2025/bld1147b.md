# Accelerating open source accessibility with GitHub Copilot

**Wed Oct 29 2025, 4:15 PM–4:55 PM PDT** · [BATS Theatre](../../rooms/bats-theatre-fort-mason-building-b.yaml)

**Speakers:** [Arnaud Leymet](../../people/arnaud-leymet.md)

Imagine learning to fly while building an airplane.

That was Arnaud's reality when creating a platform to democratize open source software with zero Rust experience. You’ll learn how GitHub Copilot became his literal copilot, transforming learning curves into tailwinds. From crafting a multi-language desktop app to curating over 170 one-click deployable stacks, you'll discover how AI amplified his capabilities and leave with battle-tested strategies to supercharge your own development velocity.

- **Type:** Breakout Session
- **Track:** Build
- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Continuous Integration + Continuous Deployment (CI/CD), Containerized applications, Open source, Productivity
- **GitHub products:** GitHub Copilot, VS Code
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Startups
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml), [Rust](../../software/rust.yaml)
