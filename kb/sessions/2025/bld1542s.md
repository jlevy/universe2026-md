# Building AI agents with VS Code and GitHub

**Wed Oct 29 2025, 2:00 PM–3:00 PM PDT** · [Sandbox](../../rooms/sandbox-firehouse.yaml)

**Speakers:** [Rong Lu](../../people/rong-lu.md) (facilitator), [April Gittens](../../people/april-gittens.md) (facilitator)

In this interactive session, you’ll build and deploy an AI agent using the latest AI Toolkit and GitHub Copilot features inside VS Code. You'll start with a prototype setup, where Copilot connects to the AI Toolkit through an MCP server to suggest models, open the model playground, instrument code for tracing, enable viewing traces, and finally deploy the agent to Azure. You’ll leave with a functioning, traced, and deployed agent — plus a repeatable local-to-cloud workflow.

- **Type:** Sandbox Session
- **Track:** Build
- **Level:** Level 300: Advanced
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Automated Infrastructure Deployment, Cloud-native development, Monitoring and observability, Testing and related practices, Productivity, Code quality, review, and completion, IDE Integration
- **GitHub products:** GitHub Copilot, VS Code
- **Audience:** Enterprise - Developer, Open Source Developer or Maintainer, Startups, Educators & Students
- **Mentions:** [Visual Studio Code](../../software/vs-code.yaml), [GitHub Copilot](../../software/github-copilot.yaml), [Model Context Protocol](../../software/model-context-protocol.yaml), [Microsoft Azure](../../software/azure.yaml)
