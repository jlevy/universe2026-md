# Making security everyone's job (without making it everyone's problem)

**Tue Oct 28 2025, 2:30 PM–3:30 PM PDT** · [Discussions Lounge](../../rooms/discussions-lounge-fort-mason-building-d.yaml)

**Speakers:** [Mario Landgraf](../../people/mario-landgraf.md) (facilitator), [Marie Theresa Brosig](../../people/marie-theresa-brosig.md) (facilitator)

In a shared responsibility model, where both developers and security and IT teams share responsibility for security, GitHub Advanced Security (GHAS) plays a crucial role. But the other crucial role is that of the community manager, the person who fosters a culture of security and knowledge sharing, and who helps make sure that security measures are continuously improving. 

It's this combination of GHAS and a community manager that enables a holistic and robust security posture at an organization. And in this interactive group discussion, you're invited to bring your own best practices, challenges, and questions to the table — whether you're looking to enhance the technical aspects of your security strategy, the human ones, or both.

- **Type:** Discussions Lounge
- **Track:** Secure
- **Level:** Level 100: Introductory
- **Topics:** Agile practices, Security (RASP, supply chain, threat modeling, vulnerability detection), Tech debt and security debt, Education, Governance and compliance
- **GitHub products:** GitHub Advanced Security, GitHub Copilot, Dependabot, GitHub Secret Protection, GitHub Code Security
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Security Professional, Startups, Security Leadership, Educators & Students
- **Mentions:** [GitHub Advanced Security](../../software/github-advanced-security.yaml)
