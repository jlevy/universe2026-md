# GitHub Code Security in action: Accelerating risk reduction at enterprise scale

**Tue Oct 28 2025, 3:20 PM–3:50 PM PDT** · [Main Stage](../../rooms/main-stage-festival-pavilion.yaml)

**Speakers:** [Bas van Schaik](../../people/bas-van-schaik.md), [Pierre Tempel](../../people/pierre-tempel.md)

How do you secure thousands of repositories without slowing developers down? In this session, GitHub’s Pierre Tempel and Bas van Schaik will show how buildless, incremental CodeQL analysis and Copilot Autofix enable code scanning and remediation at enterprise scale.
