# Power to the people: How Duke Energy built a thriving developer community

**Tue Oct 28 2025, 10:30 AM–11:10 AM PDT** · [BATS Theatre](../../rooms/bats-theatre-fort-mason-building-b.yaml)

**Speakers:** [Kal Schumacher](../../people/kal-schumacher.md)

Join Kal Schumacher, cloud engineer at Duke Energy, as he shares the company's journey from siloed teams to a unified developer community. He'll explore how this community made it possible to streamline a large-scale migration (from a variety DevOps tools), accelerate AI adoption, and fully adopt the GitHub platform. As he walks through the team's transformative actions, you'll learn how to build a collaborative ecosystem that empowers developers through innersource practices, cross-functional team collaboration, and deep engagement with the GitHub platform.

- **Type:** Breakout Session
- **Track:** Automate
- **Level:** Level 200: Intermediate
- **Topics:** Accessibility, Agile practices, AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Cloud-native development, Continuous Integration + Continuous Deployment (CI/CD), Containerized applications, DevOps and DevSecOps, Git and code management techniques, Open source, Pair programming, Social impact, Collaboration, Productivity, Platform engineering, Code quality, review, and completion, Custom integrations and APIs, Education, Migration strategies, IDE Integration
- **GitHub products:** Actions, GitHub Advanced Security, GitHub Copilot, Dependabot, GitHub Secret Protection, GitHub Code Security, GitHub Enterprise Cloud, VS Code, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Startups, Educators & Students
- **Mentions:** [Duke Energy](../../organizations/duke-energy.md)
