# Keeping developers safe: How GitHub protects against malware, abuse, and other online harms

**Tue Oct 28 2025, 3:30 PM–4:10 PM PDT** · [BATS Theatre](../../rooms/bats-theatre-fort-mason-building-b.yaml)

**Speakers:** [Tom Thorley](../../people/tom-thorley.md)

GitHub is built on the power of community—helping developers stay productive while keeping the software ecosystem secure. As we integrate agentic AI across the platform, new safety challenges emerge. To support a growing, vibrant, and safe community, GitHub is investing in AI for safety and focusing on reducing malware. In this session, we’ll share how we’re tackling abuse, fraud, and online harms through strategies like malware detection, Safety-by-Design, and AI-powered protections. You’ll get an inside look at how we’re embedding safety into every layer of the platform to help keep developers and software secure.

- **Type:** Breakout Session
- **Track:** Secure
- **Level:** Level 100: Introductory
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Data (analytics, management, privacy), Open source, Security (RASP, supply chain, threat modeling, vulnerability detection), Tech debt and security debt, Governance and compliance
- **Audience:** Enterprise - Engineering Leadership, Open Source Developer or Maintainer, Security Professional, Security Leadership
