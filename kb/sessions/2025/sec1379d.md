# Say goodbye to static credentials with ephemeral SSH certificates

**Tue Oct 28 2025, 10:30 AM–10:45 AM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Gabriele Mattutzu](../../people/gabriele-mattutzu.md)

Static credentials like Secure Shell (SSH) keys and personal access tokens (PATs) can create hidden security risks and headaches for teams. But there’s a better way. In this session, you’ll learn how to move beyond static credentials by using short-lived, ephemeral SSH certificates. We’ll show you how GitHub, combined with your identity provider and a certificate-issuing service, can eliminate the need for long-lived tokens — making access simpler, safer, and more scalable. You'll gain practical insights on how to improve your security posture, streamline credential management, and give developers a smoother, more secure experience.
