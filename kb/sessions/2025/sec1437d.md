# Improving C/C++ code quality and security with CodeQL coding standards

**Wed Oct 29 2025, 11:35 AM–11:50 AM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Mike Fairhurst](../../people/mike-fairhurst.md)

CodeQL provides GitHub users and customers with scalable, on-demand static analysis via GitHub Code Security. For C and C++ developers, code quality and security are deeply intertwined. In this session, you'll learn how to enable additional CodeQL checks aligned with industry standards — including CERT, MISRA, and AUTOSAR — to improve safety, quality, and correctness in your codebases. We’ll walk through how to select from over 1,000 CodeQL queries, integrate them with GitHub Copilot Autofix and security campaigns, and apply them in a click-to-fix workflow that supports maintainable and secure development.

- **Level:** Level 200: Intermediate
- **Topics:** DevOps and DevSecOps, Open source, Tech debt and security debt, Code quality, review, and completion
- **GitHub products:** GitHub Advanced Security
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Security Professional, Security Leadership
