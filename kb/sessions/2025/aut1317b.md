# Banking on GenAI: Leveraging Copilot as a strategic accelerator for legacy modernization

**Tue Oct 28 2025, 1:30 PM–2:10 PM PDT** · [Cowell Theater](../../rooms/cowell-theater-gateway-pavilion-level-1.yaml)

**Speakers:** [Richard Birkby](../../people/richard-birkby.md), [Ubaldo Matty](../../people/ubaldo-matty.md)

In this session, you'll dive into how global financial institution HSBC used GitHub Copilot to accelerate the migration of over 100 legacy Java APIs from Apache Camel to Spring Boot. Facing challenges around fragile code and lost institutional knowledge, the team achieved remarkable results: reducing per-API conversion time from 20 hours to under 2 hours — a 60–90% effort savings per migration— while boosting overall developer productivity by 15% in time spent coding and achieving 80%+ satisfaction sentiment across the team. The solution delivered secure-by-default improvements, with test coverage and documentation generated, scaling GitHub Copilot from a trial to 20,000+ users across the enterprise. 

In this talk, Ubaldo and Richard will walk through their technical approach to Copilot-assisted migrations, share the governance framework that enabled enterprise-wide adoption, and demonstrate how financial institutions can leverage AI to tackle legacy modernization at scale while maintaining security and compliance standards.
