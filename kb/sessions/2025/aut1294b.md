# Dawn of the agents: Leveraging AI-powered tools to accelerate software development

**Tue Oct 28 2025, 10:30 AM–11:10 AM PDT** · [Cowell Theater](../../rooms/cowell-theater-gateway-pavilion-level-1.yaml)

**Speakers:** [Nick Liffen](../../people/nick-liffen.md), [Maya Ross](../../people/maya-ross.md)

What if your team had extra help tackling the busywork of software development? What does the next wave of building software in the enterprise really look like? In this fast paced session, we’ll explore how AI-powered agents are transforming the development journey, from brainstorming to deployment, and even how we tackle code quality. We’ll look at the evolution ahead, what to expect over the next 12, 24, and 36 months, and share real world demos showing agents co-creating code, reviewing pull request, fixing bugs, and more. All while staying inside the guardrails that matter to your business. 

You’ll leave with a clear picture of how AI can help developers focus on what they do best: creative, impactful work — and what “good” looks like for enterprise software development in the years to come. Oh, and yes, there’ll be a few surprises and swag hand outs along the way!!

- **Type:** Breakout Session
- **Track:** Build, Automate
- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Cloud-native development, Tech debt and security debt, Code quality, review, and completion, Governance and compliance
- **GitHub products:** Actions, GitHub Advanced Security, Codespaces, GitHub Copilot, Dependabot, GitHub Secret Protection, GitHub Code Security, GitHub Copilot Workspace, VS Code, GitHub Spark, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Security Leadership
