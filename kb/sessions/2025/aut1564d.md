# Improve quality and speed across the SDLC with Atlassian Rovo Dev

**Tue Oct 28 2025, 3:10 PM–3:25 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Jovana Dunisijevic](../../people/jovana-dunisijevic.md)

**Hosted by:** [Atlassian](../../organizations/atlassian.md)

Atlassian Rovo Dev is an AI-powered solution that transforms the software development lifecycle (SDLC) by automating repetitive tasks and boosting productivity. This session explores how Rovo Dev agents streamline every SDLC phase — from planning to deployment — so developers can focus on innovation. 

You'll hear about real use cases where integrating GitHub and Atlassian tools delivers tangible workflow improvements and see how Jira connects with GitHub Copilot's coding agent. Ready to discover how Rovo Dev’s integration and intelligent automation can help teams deliver software faster, reduce bottlenecks, and uphold engineering standards? This session is for you.

- **Type:** Product Demo
- **Track:** Build, Automate
- **Level:** Level 200: Intermediate
- **Topics:** Agile practices, AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), DevOps and DevSecOps, Collaboration, Productivity
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer
- **Mentions:** [Jira](../../software/jira.yaml), [GitHub Copilot](../../software/github-copilot.yaml)
