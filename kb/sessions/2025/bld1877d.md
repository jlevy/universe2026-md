# Accelerate cloud migration with Arm’s MCP Server and agentic workflows

**Tue Oct 28 2025, 1:10 PM–1:25 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Pareena Verma](../../people/pareena-verma.md)

**Hosted by:** [Arm](../../organizations/arm.md)

Simplify and accelerate your cloud migrations with Arm’s MCP Server and agentic workflows.

Arm’s new MCP Server empowers AI assistants — like GitHub Copilot — to deliver expert cloud migration and optimization guidance tailored for Arm platforms. With this solution, users can unlock seamless tool usage through AI, tap into deep knowledge from vectorized tutorials and libraries, and benefit from prompts that dynamically embed expert tuning techniques to match your unique migration scenario.

In this session, you'll discover how the latest Linux migration tools on GitHub enable container image inspection, porting advice, and system performance monitoring, analysis, and reporting — all designed to streamline and speed up your migration journey with modern, agentic solutions.

- **Type:** Product Demo
- **Track:** Build, Automate
- **Level:** Level 200: Intermediate
- **Topics:** AI (Agentic AI, Generative AI, Fine-tuned modeling, Models), Cloud-native development, Continuous Integration + Continuous Deployment (CI/CD), Containerized applications, DevOps and DevSecOps, Kubernetes, Infrastructure as code, Monitoring and observability, Open source, Testing and related practices, Collaboration, Productivity, Platform engineering, Code quality, review, and completion, Custom integrations and APIs, Migration strategies, IDE Integration
- **GitHub products:** Actions, GitHub Copilot, GitHub Enterprise Cloud, VS Code, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Startups, Educators & Students
- **Mentions:** [Model Context Protocol](../../software/model-context-protocol.yaml), [GitHub Copilot](../../software/github-copilot.yaml), [Linux](../../software/linux.yaml)
