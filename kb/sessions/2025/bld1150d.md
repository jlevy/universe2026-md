# Project management? There's a GitHub tool for that

**Wed Oct 29 2025, 3:50 PM–4:05 PM PDT** · [Demos & Donuts](../../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Tomiwa Ibiwoye](../../people/tomiwa-ibiwoye.md) (facilitator)

GitHub Projects is more than just a kanban board — it’s the hidden gem powering our multi-repo, multi-product workflow. In this session, we'll share how we run AI-driven experiences, AR activations, and full-stack web apps using GitHub Projects to track work, automate updates, and replace third-party tools. Whether you're flying solo or leading a team, this talk will show you how to unlock the project management power already living inside your repo.

- **Type:** Product Demo
- **Track:** Build, Automate
- **Level:** Level 100: Introductory
- **Topics:** Agile practices, Continuous Integration + Continuous Deployment (CI/CD), Productivity, Tech debt and security debt
- **GitHub products:** Actions, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Startups
- **Mentions:** [GitHub Issues and Projects](../../software/github-issues-projects.yaml)
