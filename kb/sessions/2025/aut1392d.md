# Discover the wide world of MCP servers

**Wed Oct 29 2025, 3:40 PM–3:55 PM PDT** · [Silent Disco Demos](../../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [Reynald Adolphe](../../people/reynald-adolphe.md)

During this MCP server “safari” through VS Code’s agent mode, you’ll see first-hand how MCP servers enable agent mode to use a browser, download images for design, search the internet, turn the lights off(!), and more. You’ll also explore powerful workflows that give agent mode the context it needs to boost your productivity and get your todos done faster.
