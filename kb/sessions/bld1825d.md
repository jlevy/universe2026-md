# Modernizing CI/CD with agents, GitHub Actions, and human oversight (Sponsored)

**Wed Oct 28 2026, 10:50 AM–11:05 AM PDT** · [Demos & Donuts](../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Mitch Enderle](../people/mitch-enderle.md), [Sai Gade](../people/sai-gade.md)

**Hosted by:** [UST](../organizations/ust.md)

At enterprise scale, CI/CD modernization can feel less like a migration and more like untangling years of custom pipelines, dependencies, controls, and delivery commitments. This session will demonstrate how agents helped CVS Health and UST moved from Jenkins to GitHub Actions by reducing repetitive work and keeping engineers in full control.  

You’ll see how an enterprise put agents to work in a complex migration, and leave with a practical way to plan a CI/CD modernization that addresses legacy complexity today while creating a foundation for future agent-powered development.

- **Type:** Product Demo
- **Track:** Build software, not code
- **Level:** Level 200: Intermediate
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), Governance and compliance, Migration strategies, AI: Agents
- **GitHub products:** Actions, GitHub Enterprise Cloud, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer
- **Mentions:** [GitHub Actions](../software/github-actions.yaml), [CVS Health](../organizations/cvs-health.md), [Jenkins](../software/jenkins.yaml)
