# Supply chain controls for AI agents with JFrog and GitHub (Sponsored)

**Wed Oct 28 2026, 11:50 AM–12:05 PM PDT** · [Demos & Donuts](../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Ronen Lewit](../people/ronen-lewit.md)

**Hosted by:** [JFrog](../organizations/jfrog.md)

As AI agents produce more code, teams need to know what those agents bring into a build and how to verify what ships. This demo shows how JFrog works with GitHub to control which models, MCP servers, and packages agents use; replace supported vulnerable dependencies with patched versions when available; and enforce compliance policies using signed evidence. You’ll see where those controls fit in the development workflow and what teams can review when auditing a release.

- **Type:** Product Demo
- **Track:** Build software, not code
- **Level:** Level 100: Introductory
- **Topics:** DevOps and DevSecOps, Open source, Security (RASP, supply chain, threat modeling, vulnerability detection), Governance and compliance, AI: MCP and other integrations, AI: Models
- **GitHub products:** Actions, Supply Chain Security, GitHub Copilot, Dependabot, GitHub Code Security, VS Code
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Security Professional, Startups, Security Leadership, Educators & Students
- **Mentions:** [Model Context Protocol](../software/model-context-protocol.yaml)
