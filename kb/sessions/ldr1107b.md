# The human side of AI: How building community drove 94% Copilot adoption

**Wed Oct 28 2026, 4:30 PM–5:10 PM PDT** · [BATS Theatre](../rooms/bats-theatre-fort-mason-building-b-3rd-floor.yaml)

**Speakers:** [Brittany Istenes](../people/brittany-istenes.md)

What if scaling AI isn’t about better models, but better human connection? Learn how a large U.S.-based financial services firm achieved 94% GitHub Copilot adoption and 78% agent-written code by combining grassroots engagement, storytelling, and innersource, making AI something developers wanted to use and build together. This session shares how treating AI adoption as a people challenge drives trust, plus how to measure meaningful adoption through impact.

- **Type:** Breakout Session
- **Track:** Build software, not code, Lead through what's next
- **Level:** Level 200: Intermediate
- **Topics:** Community and social impact, Testing and related practices, Productivity, Education, Governance and compliance, Developer experience (DX)
- **GitHub products:** GitHub Copilot, VS Code
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Security Professional, Security Leadership, Educators & Students
- **Mentions:** [GitHub Copilot](../software/github-copilot.yaml)
