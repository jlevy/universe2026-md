# Humans set direction. Agents close the loop.

**Wed Oct 28 2026, 11:15 AM–11:45 AM PDT** · [Main Stage](../rooms/main-stage-festival-pavilion.yaml)

**Speakers:** [Mario Rodriguez](../people/mario-rodriguez.md), [Evan Boyle](../people/evan-boyle.md)

The value of an agent isn’t measured by how much code it writes, but by how much software work it finishes. Agents are moving beyond code generation to help plan, review, secure, deploy, and operate software. In this session, GitHub Chief Product Officer Mario Rodriguez explores a new operating model where developers define the outcomes and standards, agents carry work through the development loop, and people remain accountable for what ships. See how GitHub is connecting the context, workflows, and controls teams need to delegate more ambitious work with confidence.

- **Type:** Main Stage
- **Track:** Build software, not code, Lead through what's next
- **Level:** Level 100: Introductory
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), Data (analytics, management, privacy), DevOps and DevSecOps, Open source, Collaboration, Productivity, Platform engineering, Code quality, review, and completion, AI: Agents, AI: Models, Developer experience (DX)
- **GitHub products:** GitHub Copilot, GitHub Enterprise Cloud, GitHub Enterprise Server
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Security Professional, Startups, Security Leadership, Educators & Students
