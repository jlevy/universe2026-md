# Work together, your way, with GitHub Copilot

**Wed Oct 28 2026, 1:40 PM–2:10 PM PDT** · [Main Stage](../rooms/main-stage-festival-pavilion.yaml)

**Speakers:** [Burke Holland](../people/burke-holland.md), [James Montemagno](../people/james-montemagno.md), [Pierce Boggan](../people/pierce-boggan.md), [Julia Kasper](../people/julia-kasper.md), [Katie Savage](../people/katie-savage.md)

Your team might agree on what to build, but how to build it is another conversation. Join Pierce Boggan and team as they tackle a shared project with GitHub Copilot, bringing their favorite tools, models, and a few strong opinions. Working across the Copilot app, CLI, VS Code, and JetBrains, they’ll put agents to work, carry context between tasks, and take development beyond the editor, balancing speed, cost, and control a little differently. Follow the project from idea to working software to see how the latest in Copilot helps a team build together without making everyone work the same way.

- **Track:** Build software, not code
- **Level:** Level 200: Intermediate
- **Topics:** Productivity, AI: Agents, AI: MCP and other integrations, AI: Models, Developer experience (DX)
- **GitHub products:** GitHub Copilot, VS Code
- **Audience:** Enterprise - Developer, Open Source Developer or Maintainer, Startups
- **Mentions:** [GitHub Copilot](../software/github-copilot.yaml), [Visual Studio Code](../software/vs-code.yaml)
