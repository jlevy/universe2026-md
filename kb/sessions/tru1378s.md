# Capture the flag: Three AI teams, one codebase, zero mercy

**Wed Oct 28 2026, 12:50 PM–1:35 PM PDT** · [Sandbox](../rooms/sandbox-fort-mason-building-c-founders-inc-3rd-floor.yaml)

**Speakers:** [Christophe Crémon](../people/christophe-cremon.md) (facilitator), [Romain Le Disez](../people/romain-le-disez.md) (facilitator)

Capture the flag is the most iconic format in cybersecurity, so we turned it into a live GitHub battle. Three squads of AI agents compete on the same codebase in real time: a Dev Team ships features, a Red Team sneaks in vulnerabilities, and a Blue Team hunts them down with GitHub Advanced Security as the referee.

The agents run on Squad (by Brady Gaster), and Pixel Agents makes their every move visible on screen. You won't just hear about agentic workflows and security controls at enterprise scale, you'll watch them collide, live.

You'll leave knowing which GitHub security controls are non-negotiable for AI-generated code and with the open source repo to run the match yourself.

- **Type:** Sandbox Session
- **Track:** Trust every commit
- **Level:** Level 200: Intermediate
- **Topics:** DevOps and DevSecOps, Open source, Security (RASP, supply chain, threat modeling, vulnerability detection), Collaboration, Code quality, review, and completion, AI: Agents, AI: MCP and other integrations
- **GitHub products:** Actions, Supply Chain Security, GitHub Copilot, GitHub Secret Protection, GitHub Code Security, GitHub Enterprise Cloud, VS Code, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Security Professional, Security Leadership
- **Mentions:** [GitHub Advanced Security](../software/github-advanced-security.yaml)
