# Automating PR quality with Copilot CLI and GitHub Actions

**Thu Oct 29 2026, 10:40 AM–10:55 AM PDT** · [Demos & Donuts](../rooms/demos-donuts-gateway-pavilion-level-2.yaml)

**Speakers:** [Simona Toader](../people/simona-toader.md)

Pull requests are often where quality deteriorates, from missing documentation and weak tests to delayed security feedback. This product demo shows how GitHub Copilot CLI and GitHub Actions can generate documentation, create unit tests, and run security checks on every commit and pull request, helping teams improve quality without slowing developers down.

- **Type:** Product Demo
- **Track:** Build software, not code, Lead through what's next
- **Level:** Level 300: Advanced
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), DevOps and DevSecOps, Security (RASP, supply chain, threat modeling, vulnerability detection), Testing and related practices, Platform engineering, AI: Agents, Developer experience (DX)
- **GitHub products:** Actions, Supply Chain Security, GitHub Copilot, GitHub Enterprise Cloud, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Security Professional, Startups, Security Leadership
- **Mentions:** [GitHub Copilot CLI](../software/copilot-cli.yaml), [GitHub Actions](../software/github-actions.yaml)
