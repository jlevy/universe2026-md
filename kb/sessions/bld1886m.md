# What's worth building when AI can build anything?

**Thu Oct 29 2026, 9:50 AM–10:20 AM PDT** · [Main Stage](../rooms/main-stage-festival-pavilion.yaml)

**Speakers:** [Kent C. Dodds](../people/kent-c-dodds.md), [Sue Black](../people/sue-black.md)

AI can build almost anything you ask it to, which makes a harder question unavoidable: what's actually worth building? In this conversation, Sue Black of Durham University and Kent C. Dodds of kody.codes make the case for building deliberately rather than reflexively. 

This session will explore what responsible software looks like and take a deeper dive into the daily reality of shipping, choosing between tools, and maintaining what’s already built. You'll leave with a sharper set of questions to bring to your own work, along with a clearer sense of when speed is worth it and when it isn't.

- **Type:** Main Stage
- **Track:** Build software, not code
- **Level:** Level 100: Introductory
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), Git and code management techniques, Open source, Collaboration, Platform engineering, Code quality, review, and completion
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Startups, Educators & Students
- **Mentions:** [Durham University](../organizations/durham-university.md), [kody.codes](../organizations/kody-codes.md)
