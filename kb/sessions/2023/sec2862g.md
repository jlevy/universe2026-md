# Dependencies wrangled: proven practices to secure the software supply chain

**Wed Nov 8 2023, 3:30 PM–4:10 PM PST** · [Screening Room](../../rooms/ybca-screening-room.yaml)

**Speakers:** [Justin Hutchings](../../people/justin-hutchings.md), [Christopher Angelo Phillips](../../people/christopher-angelo-phillips.md)

Zero days. Executive orders. Oceans of alerts. But it’s not all bad news! Advances in coverage, relevance, and automation make it easier than ever to wrangle your dependencies once and for all. 

In this session, GitHub experts will show you how to silence the noise, automate manual tasks, and execute remediation with confidence. Then, our friends at Anchore will share how they reduced false positives in Grype by 80%, and how you can also level up your supply chain security game with GitHub’s free, native resources. Finally, we share a sneak peek at new capabilities that free up more time to write great code.

- **Type:** General Session
- **Track:** Security
- **Level:** Level 100: Introductory
- **Topics:** DevSecOps, Security, Supply Chain Security, Vulnerability Detection
- **GitHub products:** Advanced Security, Supply Chain Security
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Security Leadership
- **Mentions:** [Anchore](../../organizations/anchore.md)
