# Passwordless deployments with GitHub Actions to the cloud

**Wed Nov 8 2023, 10:30 AM–11:10 AM PST** · [Screening Room](../../rooms/ybca-screening-room.yaml)

**Speakers:** [Radoslav Gatev](../../people/radoslav-gatev.md)

Using secrets and certificates for system-to-system communication often proves cumbersome and prone to leakage. Why bother with credentials when there is a more secure and easy approach, like going passwordless? In this talk, you will learn how to leverage the power of OpenID Connect to authenticate your GitHub Actions when deploying to Microsoft Azure.

This session will delve into the fundamentals of OpenID Connect and its integration with GitHub Actions. Discover practical techniques to organize workflows effectively at an organizational level, implement federated credentials, and facilitate token exchange.
