# Putting cybersecurity advocacy into action with GitHub Advanced Security

**Wed Nov 8 2023, 3:45 PM–4:25 PM PST** · [Main Stage](../../rooms/ybca-main-stage.yaml)

**Speakers:** [Marie Theresa Brosig](../../people/marie-theresa-brosig.md)

Security and development teams are often at odds. But there is a way to (metaphorically) reach across the table and come together to achieve a common goal: to write, build, and run your company’s software more securely. 

In this session, I’ll be using the rollout of GitHub Advanced Security (GHAS) to illustrate how you can apply cybersecurity advocacy concepts to build new relationships with developers and strengthen existing ones, and how to engage and interact with developers in a more developer-friendly way.

- **Level:** Level 100: Introductory
- **Topics:** Security, Supply Chain Security, Collaboration, Community
- **GitHub products:** Advanced Security, Supply Chain Security
