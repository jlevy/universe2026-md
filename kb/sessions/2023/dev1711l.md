# GitHub productivity via VS Code for rapid-context-switchers like me

**Thu Nov 9 2023, 10:30 AM–11:10 AM PST** · [Discussions Lounge](../../rooms/ybca-discussions-lounge.yaml)

**Speakers:** [Jay Miller](../../people/jay-miller.md) (facilitator)

The current developer space rarely allows for long periods of "do one thing at a time." This is all amplified by coworkers and family members demanding attention, or maybe even your physical and mental health needs. 

In this session, we'll dive into GitHub and VS Code features and extensions that you can leverage to keep up on or at least "close" your tasks. You'll learn how you can transform your editor into a productive space that allows you to keep focus and accomplish what you need to do. 

Bring your favorite tips, tricks, and extensions, and be ready for an insightful and collaborative discussion.

- **Type:** Discussion Lounge
- **Track:** AI, Developer Experience
- **Level:** Level 200: Intermediate
- **Topics:** Accessibility, Continuous Integration + Continuous Deployment (CI/CD), Git and related code management techniques, Human Factors, Infrastructure as Code, Open Source, Productivity
- **GitHub products:** Actions, Codespaces, Copilot, Issues
- **Audience:** Enterprise - Developers, Open Source Developers or Maintainers
- **Mentions:** [Visual Studio Code](../../software/vs-code.yaml)
