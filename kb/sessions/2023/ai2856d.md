# Hassle-free pull requests with GitHub Copilot

**Wed Nov 8 2023, 12:00 PM–12:25 PM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Calvin Chang](../../people/calvin-chang.md), [Bassem Dghaidi](../../people/bassem-dghaidi.md)

Pull requests can vary greatly in quality. Exceptional PRs provide essential context, clear problem statements, well-thought-out solutions, adequate testing, and robust security considerations. Yet, the truth is that software engineers often feel that providing all this context is both tedious and repetitive.

In this session, we’ll explore how GitHub Copilot can simplify your PR workflow, taking care of the repetitive tasks and allowing you to concentrate on creating better PRs, every time. We’ll also dive into how you can leverage GitHub Copilot to dive deeper into PRs created by others.

- **Track:** AI, Security

- **GitHub products:** Copilot
