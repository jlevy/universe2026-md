# Workshop: Certification workshop: GitHub Advanced Security

**Wed Nov 8 2023, 10:30 AM–12:00 PM PST** · [Hyatt - Gallery Ballroom II](../../rooms/hyatt-gallery-ballroom-ii.yaml)

**Speakers:** [Greg Mohler](../../people/greg-mohler.md) (facilitator), [Kristen Newbury](../../people/kristen-newbury.md) (facilitator)

**Session must be added during registration in order to add to your schedule** Exams can be tough. Not everyone loves them. But no matter your opinion, this workshop will equip all participants with the practical knowledge and skills needed to pass the GitHub Advanced Security (GHAS) certification exam with flying colors. The agenda will move quickly through the basics, and focus most of the time covering the functionality and configuration options that are brought up in the exam. 

Attendees will use their own laptops to instrument GitHub security features in this interactive workshop.

- **Type:** Workshop
- **Track:** Developer Experience, Security
- **Level:** Level 200: Intermediate
- **Topics:** DevSecOps, Security, Supply Chain Security, Threat Modeling, Vulnerability Detection
- **GitHub products:** Actions, Advanced Security
- **Audience:** Enterprise - Developers, Security Professionals
- **Mentions:** [GitHub Advanced Security](../../software/github-advanced-security.yaml)
