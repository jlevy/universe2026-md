# In the pipe, five by five: GitHub Copilot and automated security

**Thu Nov 9 2023, 11:30 AM–11:55 AM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Andrew Hoog](../../people/andrew-hoog.md)

After the initial joy of GitHub Copilot completing code for you, you should focus on making sure the code is secure, free of privacy and app store blockers, and performs as expected.

This is where automated security testing pairs perfectly with GitHub Copilot to support developers and protect your users. By automating static and dynamic analysis with GitHub Actions and GitHub Advanced Security, developers can easily detect and remediate bugs in commits and pull requests! This technical talk will use live demos to show you how to ship mobile apps with high confidence.

- **Type:** Product Demo
- **Track:** AI, Developer Experience, Security
- **Level:** Level 100: Introductory
- **Topics:** Artificial Intelligence (AI), Continuous Integration + Continuous Deployment (CI/CD), DevOps, DevSecOps, Security
- **GitHub products:** Actions, Advanced Security, Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Startups, Security Leadership, Educators
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml), [GitHub Actions](../../software/github-actions.yaml), [GitHub Advanced Security](../../software/github-advanced-security.yaml)
