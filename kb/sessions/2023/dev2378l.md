# Migrating 1.5k repos to GitHub: an interactive discussion on mistakes, tools, and lessons learned

**Wed Nov 8 2023, 10:30 AM–11:10 AM PST** · [Discussions Lounge](../../rooms/ybca-discussions-lounge.yaml)

**Speakers:** [Sai Gunaranjan](../../people/sai-gunaranjan.md) (facilitator), [Kyler Middleton](../../people/kyler-middleton.md) (facilitator)

Migrating 1.5k repos from an internal Bitbucket server to GitHub is an enormous technical and process challenge. Doing it without causing interruption? And at scale? Almost an impossible feat. 

Come participate in a discussion about mistakes to avoid, the tools and GitHub Actions used, and the lessons learned in the process.

- **Track:** Developer Experience, Security
- **Level:** Level 200: Intermediate
- **Topics:** Agile practices, Continuous Integration + Continuous Deployment (CI/CD), DevOps, DevSecOps, Git and related code management techniques, Human Factors, Open Source, Security, Shell Programming (Bash, PowerShell, etc.), Software Engineering, Testing and related practices, Collaboration, Productivity
- **GitHub products:** Actions, Advanced Security
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Startups
- **Mentions:** [GitHub Actions](../../software/github-actions.yaml)
