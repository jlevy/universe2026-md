# GitHub Advanced Security: Code Scanning

**Wed Nov 8 2023, 1:00 PM–1:25 PM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Walker Chabbott](../../people/walker-chabbott.md), [AlonaHlobina](../../people/alonahlobina.md), [Mathew Payne](../../people/mathew-payne.md)

Static application security testing, enhanced through AI. In this demo, you’ll take a deep dive into GitHub Advanced Security’s code scanning feature, which empowers developers to effortlessly prevent and fix vulnerabilities as they write code, while staying in their workflow. We’ll show you the power of our auto-remediation capabilities, which serves up proposed AI-generated fixes for CodeQL alerts in pull requests. Learn more about how code scanning supports easy collaboration, prevention, and remediation with features that developers—and security professionals—will love.

- **Level:** Level 100: Introductory
- **Topics:** Artificial Intelligence (AI), DevSecOps, Vulnerability Detection
