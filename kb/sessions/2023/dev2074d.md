# Using OIDC to interact with AWS from GitHub Actions

**Wed Nov 8 2023, 4:00 PM–4:25 PM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Mike Stemle](../../people/mike-stemle.md)

GitHub Actions and AWS services are separate product offerings by different organizations, but that doesn't mean they can't play together. In this talk, you'll learn how to use OIDC to allow interaction between these two systems and pick up best practices for working with AWS from GitHub Actions in a safe, convenient, and fun way.

- **Type:** Product Demo
- **Track:** Developer Experience
- **Level:** Level 300: Advanced
- **Topics:** Automated Infrastructure Deployment, Cloud, Continuous Integration + Continuous Deployment (CI/CD), Security, Collaboration, Productivity
- **GitHub products:** Actions
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Security Professionals, Security Leadership
- **Mentions:** [Amazon Web Services](../../software/aws.yaml), [GitHub Actions](../../software/github-actions.yaml)
