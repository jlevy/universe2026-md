# Workshop: Understanding the risk of script Injections in GitHub Actions workflows

**Tue Nov 7 2023, 3:30 PM–5:00 PM PST** · [Hyatt - Gallery Ballroom II](../../rooms/hyatt-gallery-ballroom-ii.yaml)

**Speakers:** [Robert Anderson](../../people/robert-anderson.md) (facilitator), [Yadhav Jayaraman](../../people/yadhav-jayaraman.md) (facilitator)

**Session must be added during registration in order to add to your schedule** There are lots of great use cases for using GitHub Actions with user input, either directly, or via issues, PRs, and more. That being said, taking user input and using it in your workflow can be risky if not done correctly. In this session, we'll cover why it’s important to understand script injections in GitHub Actions workflows, so you can protect secrets and keep your environment safe.

- **Track:** Developer Experience
- **Level:** Level 200: Intermediate
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), Security, Productivity
- **GitHub products:** Actions, Issues
- **Audience:** Enterprise - Developers, Open Source Developers or Maintainers
