# Safe but flexible: the DevEx-based code management culture at Mercado Libre

**Wed Nov 8 2023, 1:30 PM–2:10 PM PST** · [Screening Room](../../rooms/ybca-screening-room.yaml)

**Speakers:** [Javier Cardoso](../../people/javier-cardoso.md), [Erik Arcos](../../people/erik-arcos.md)

Join us at Mercadolibre on our journey to build a platform-based code management culture. From repository creation to the final deployment that governs over 30,000 micro-services and supports over 15,000 developers, all in a highly safe and productive environment. 

We'll discuss key insights, including the challenges we faced, the solutions we implemented, the best practices we adopted, and how we use GitHub to push the success of our vision.

- **Type:** General Session
- **Track:** AI, Developer Experience, Security
- **Level:** Level 200: Intermediate
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), Containerized Applications, DevOps, DevSecOps, Git and related code management techniques, Monitoring and Observability, Open Source, Security, Supply Chain Security, Software Engineering, Testing and related practices, Vulnerability Detection, Collaboration, Community, Productivity
- **GitHub products:** Actions, Advanced Security, Supply Chain Security, Copilot, Enterprise/Admin, Extensibility/Ecosystem
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Startups, Security Leadership
- **Mentions:** [Mercado Libre](../../organizations/mercado-libre.md)
