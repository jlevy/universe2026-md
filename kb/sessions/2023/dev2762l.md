# Coding without barriers: Help create the Open Source Accessibility Playbook

**Wed Nov 8 2023, 4:30 PM–5:10 PM PST** · [Discussions Lounge](../../rooms/ybca-discussions-lounge.yaml)

**Speakers:** [Darryl Adams](../../people/darryl-adams.md) (facilitator), [Ed Summers](../../people/ed-summers.md) (facilitator), [Jesse Dugas](../../people/jesse-dugas.md) (facilitator), [Francis Storr](../../people/francis-storr.md) (facilitator)

Intel and GitHub are collaborating on an accessibility playbook. The goal is to create a resource that can improve the accessibility and inclusion of open source projects and we need your help! No experience with accessibility? No problem. Collaborate with us and share your expectations as a potential consumer of the playbook in this brainstorming session. Together, we can create a more inclusive, accessible future for all developers.

- **Type:** Discussion Lounge
- **Track:** Developer Experience
- **Level:** Level 100: Introductory
- **Topics:** Accessibility, Continuous Integration + Continuous Deployment (CI/CD), Git and related code management techniques, Pair Programming, Scrum, Social Impact, Software Engineering, Collaboration, Community
- **GitHub products:** Extensibility/Ecosystem, Projects, Issues, Pages
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Educators
- **Mentions:** [Intel](../../organizations/intel.md)
