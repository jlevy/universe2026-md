# Workshop: GitHub DevSecOps Fundamentals

**Thu Nov 9 2023, 2:30 PM–4:00 PM PST** · [Hyatt - Gallery Ballroom II](../../rooms/hyatt-gallery-ballroom-ii.yaml)

**Speakers:** [Igwe Kalu](../../people/igwe-kalu.md) (facilitator), [Mohammad Ismail](../../people/mohammad-ismail.md) (facilitator)

**Session must be added during registration in order to add to your schedule** This GitHub DevSecOps fundamentals workshop will help you begin or level up your DevSecOps journey on GitHub. 

DevSecOps principles enable organizations to securely plan, develop, integrate, and deliver solutions; and ultimately stay competitive in business. This workshop will demonstrate how to implement DevSecOps principles, highlighting how you can use the GitHub platform to remove the complexities and complications introduced in the development process as a result of the proliferation of tools.

- **Type:** Workshop
- **Track:** Developer Experience, Security
- **Level:** Level 100: Introductory
- **Topics:** DevOps, DevSecOps, Security, Supply Chain Security, Threat Modeling, Vulnerability Detection
- **GitHub products:** Actions, Advanced Security, Enterprise/Admin
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Startups, Security Leadership
