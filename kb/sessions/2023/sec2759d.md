# GitHub Advanced Security: Supply Chain Security

**Thu Nov 9 2023, 12:00 PM–12:25 PM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Zain Malik](../../people/zain-malik.md), [Erin Havens](../../people/erin-havens.md), [Charlie Rice](../../people/charlie-rice.md)

Secure your software supply chain with GitHub Advanced Security. Protect your software from dependency-based vulnerabilities throughout the software development lifecycle with GitHub Advanced Security’s Supply Chain Security. In this demo, you’ll see how GitHub reveals contextual details about direct and transitive dependencies, including release dates, popularity, vulnerabilities, and their severity. Acting on these insights, Dependabot generates automatic pull requests with clear remediation steps so developers can resolve vulnerabilities and keep coding.
