# Streamlining DevOps: infrastructure as state at Air France KLM

**Thu Nov 9 2023, 2:30 PM–3:10 PM PST** · [Theater](../../rooms/sfmoma-theater.yaml)

**Speakers:** [Jerome Djebari](../../people/jerome-djebari.md), [Jean-François Gueyffier](../../people/jean-francois-gueyffier.md)

At Air France KLM, we started our cloud journey two years ago with 1,200 applications. Since then, we have built a far more mature DevOps practice, but sometimes key responsibilities are shared between developers and operations teams—and that can make automation challenging. For instance, our operations team provisions Azure Application Gateways via Terraform and declarative automation. But our developers manage all configurations with imperative code, which is non-idempotent and difficult to maintain.

Discover how we solved this issue at Air France KLM by implementing Infrastructure as state, thanks to GitHub Actions and a human-readable YAML contract.
