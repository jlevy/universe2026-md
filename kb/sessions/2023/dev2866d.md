# Rule GitHub with just a touch of your finger

**Thu Nov 9 2023, 12:30 PM–12:55 PM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Jillian Morgan](../../people/jillian-morgan.md)

Security is more important than ever, especially for developers. That's why 1Password has introduced a suite of tools that enable developers to interact with GitHub in a new way—one that puts security and convenience hand-in-hand. 

Join 1Password Senior Developer, Jillian Morgan, to explore how 1Password’s developer tools can streamline and secure your workflows in GitHub. Discover how you can push and pull code from GitHub, sign your Git Commits, and more, all with just a touch of your finger, whether you're using TouchID, an Apple Watch, or other forms of biometrics.

- **Type:** Product Demo
- **Track:** Developer Experience, Security
- **Level:** Level 200: Intermediate
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), DevOps, DevSecOps, Git and related code management techniques, Security, Shell Programming (Bash, PowerShell, etc.), Collaboration, Productivity
- **GitHub products:** Actions, Advanced Security, Extensibility/Ecosystem, Projects
- **Audience:** Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Startups
- **Mentions:** [1Password](../../organizations/1password.md), [Git](../../software/git.yaml)
