# Workshop: Codifying security knowledge: How to go from security advisory to CodeQL query

**Tue Nov 7 2023, 1:30 PM–3:00 PM PST** · [Hyatt - Gallery Ballroom II](../../rooms/hyatt-gallery-ballroom-ii.yaml)

**Speakers:** [Stefan Petrushevski](../../people/stefan-petrushevski.md) (facilitator), [Remco Vermeulen](../../people/remco-vermeulen.md) (facilitator), [Luke Cartey](../../people/luke-cartey.md) (facilitator)

**Session must be added during registration in order to add to your schedule** CodeQL is a semantic analysis engine that ships with rules to discover vulnerabilities. These rules are written in QL, a query language suited to investigate code. In this session, we will use QL to explore a codebase guided by a security advisory to understand how a security issue materializes. Finally, we'll create a rule that can be shared that enables variant analysis using the knowledge we codified.
