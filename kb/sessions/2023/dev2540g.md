# Navigating Liberty Mutual's seamless journey to GitHub Enterprise Cloud

**Wed Nov 8 2023, 11:30 AM–12:10 PM PST** · [Theater](../../rooms/sfmoma-theater.yaml)

**Speakers:** [Matthew Chieco](../../people/matthew-chieco.md), [Jean Desulme](../../people/jean-desulme.md)

Learn about Liberty Mutual's seamless migration from four self-hosted, globally disparate code management platforms to GitHub Enterprise Cloud over the course of 2022.  

Throughout the session, Liberty Mutual's Secure DevOps team will review why this migration was so important. They'll also cover how we made it happen without disrupting 5,000 engineers and 33,000 migrated repositories—and what's on the horizon to achieve Liberty Mutual's vision of a single, globally available, and highly resilient software delivery platform.

- **Type:** General Session
- **Track:** Developer Experience
- **Level:** Level 200: Intermediate
- **Topics:** Cloud, DevOps, DevSecOps, Git and related code management techniques, Human Factors, Collaboration, Community
- **GitHub products:** Education, Enterprise/Admin, Extensibility/Ecosystem
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers
- **Mentions:** [Liberty Mutual Insurance](../../organizations/liberty-mutual-insurance.md), [GitHub Enterprise Cloud](../../software/github-enterprise-cloud.yaml)
