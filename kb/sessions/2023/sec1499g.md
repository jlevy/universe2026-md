# Building GitHub Advanced Security in the Age of AI

**Wed Nov 8 2023, 12:30 PM–1:10 PM PST** · [Screening Room](../../rooms/ybca-screening-room.yaml)

**Speakers:** [Nick Liffen](../../people/nick-liffen.md), [Niroshan Rajadurai](../../people/niroshan-rajadurai.md)

Get a behind-the-scenes look into how GitHub builds our security products and preview what's on the horizon that answers common challenges organizations face when deploying, scaling, and running application security programs. Hear how we apply AI to our security products and strategically focus on initiatives that improve your security outcomes. Takeaway an understanding of how GitHub responds to your key challenges in driving security at scale and the opportunity AI presents to your security programs.
