# How GitHub operationalizes AI for teamwide collaboration and productivity

**Wed Nov 8 2023, 12:45 PM–1:25 PM PST** · [Main Stage](../../rooms/ybca-main-stage.yaml)

**Speakers:** [Kyle Daigle](../../people/kyle-daigle.md)

As the home for all software developers, it’s not surprising that GitHub runs like most other organizations today: using software across its own operations. Join GitHub COO Kyle Daigle for a discussion around how GitHub scaled its learnings deploying and offering GitHub Copilot–the world’s first AI pair programmer–to now applying AI across GitHub. As focal points, Kyle will detail how GitHub uses AI to improve the developer experience and support customers today and tomorrow.

- **Level:** Level 100: Introductory
- **Topics:** Artificial Intelligence (AI), DevOps, Pair Programming, Software Engineering, Collaboration, Productivity
- **GitHub products:** Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Startups
