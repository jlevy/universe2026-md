# Safeguarding software integrity: VMware's approach to source code security with GitHub

**Thu Nov 9 2023, 10:30 AM–11:10 AM PST** · [Theater](../../rooms/sfmoma-theater.yaml)

**Speakers:** [Sean Josephson](../../people/sean-josephson.md)

VMware has a very large software footprint, and currently, all its open source projects are hosted on GitHub. GitHub and its services allow VMware's engineering staff to be proactive with code security and secret management—two areas, if mishandled, can significantly impact customers and revenue.  In this session, we will be taking a deep dive into source code security and how VMware protects its customers and IP with GitHub SaaS.
