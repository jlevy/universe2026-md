# Continuous Delivery fundamentals with GitHub Actions

**Thu Nov 9 2023, 4:00 PM–4:25 PM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Usha N](../../people/usha-n.md)

Learn how GitHub Actions helps DevOps teams to setup their applications for continuous delivery (CD) all the way from code check-ins into production through various pre-production environments. GitHub Actions helps enterprises manage their releases and deployments at scale, while meeting their security and compliance needs. In this session, we’ll look into how you can define deployment Jobs that target environments, or configure approvals and protection rules that should pass before artifacts are promoted from one environment to another.

- **Topics:** Continuous Integration + Continuous Deployment (CI/CD)
