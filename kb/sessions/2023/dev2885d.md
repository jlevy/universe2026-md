# Make smarter decisions early in the development lifecycle with Docker

**Wed Nov 8 2023, 1:30 PM–1:55 PM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Christian Dupuis](../../people/christian-dupuis.md)

One of the key aspects of Docker is the ability to connect the dots across the software supply chain and present actionable solutions to developers, all in line with the flexible, iterative process of building modern applications.

In this talk, we will discuss GitHub Actions that run the Docker Scout CLI as part of your workflows, allowing you to run commands like quickview (get a quick overview of an image, base image and available recommendations), compare (compare an image to a second one), and recommendations (display available base image updates and remediation recommendations).

- **Track:** Developer Experience
- **Level:** Level 200: Intermediate
- **Topics:** Containerized Applications
- **GitHub products:** Actions
- **Audience:** Enterprise - Developers, Open Source Developers or Maintainers
