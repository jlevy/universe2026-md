# How to deploy and manage an application security program effectively

**Wed Nov 8 2023, 2:30 PM–3:10 PM PST** · [Discussions Lounge](../../rooms/ybca-discussions-lounge.yaml)

**Speakers:** [Jacob DePriest](../../people/jacob-depriest.md) (facilitator), [Greg Ose](../../people/greg-ose.md) (facilitator), [Nick Liffen](../../people/nick-liffen.md) (facilitator), [Adam Berelowitz](../../people/adam-berelowitz.md) (facilitator)

As the digital landscape continues to evolve, safeguarding applications against security threats is paramount for organizations. Let’s discuss the best practices in managing an application security program to protect valuable assets and maintain customer trust. We’ll discuss strategies for implementing a robust security framework, fostering a culture of security awareness, and integrating security into the software development lifecycle (SDLC). Additionally, we’ll explore emerging trends and technologies that can enhance application security and the importance of continuous monitoring and adaptation to stay ahead of evolving threats. Join us to ask your most pressing questions, gain insights, and learn actionable takeaways for strengthening your application security program in an ever-changing threat landscape.

- **Type:** Discussion Lounge
- **Track:** Security
- **Level:** Level 200: Intermediate
- **Topics:** Security, Threat Modeling, Vulnerability Detection
- **GitHub products:** Advanced Security
- **Audience:** Security Professionals, Security Leadership
