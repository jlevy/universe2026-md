# Quickly build and deploy OpenAI apps on Azure, infused with your own data

**Wed Nov 8 2023, 1:45 PM–2:25 PM PST** · [Main Stage](../../rooms/ybca-main-stage.yaml)

**Speakers:** [Pamela Fox](../../people/pamela-fox.md), [Savannah Ostrowski](../../people/savannah-ostrowski.md), [Mandy Whaley](../../people/mandy-whaley.md), [Shayne Boyer](../../people/shayne-boyer.md)

Unlock the world of generative AI applications and walk away with your own AI app ready to deploy. Learn to build and deploy an AI-infused, cloud-native application using VS Code, Azure Developer CLI, and GitHub Actions with Azure OpenAI. We'll walk you through a streamlined workflow that starts with GitHub and extends to Azure cloud deployment. See how this end-to-end toolkit simplifies development and offers robust testing and monitoring. We’ll also show you how to test your app using Playwright. Come learn how GitHub and Azure can help you accelerate AI-infused application development.

To discover more about Microsoft’s developer productivity resources go to  https://aka.ms/AAnkynx to learn about Azure developer tooling, explore SDKs on the Azure GitHub Repo, and learn about GitHub concepts with the Cloud Skills Challenge.

- **Type:** Main Stage
- **Track:** Developer Experience
- **Level:** Level 100: Introductory
- **Topics:** Agile practices, Artificial Intelligence (AI), Cloud, Continuous Integration + Continuous Deployment (CI/CD), Data Analytics, Data Management, DevOps, Open Source, Software Engineering, Testing and related practices, Collaboration, Community, Productivity
- **GitHub products:** Actions, Enterprise/Admin, Extensibility/Ecosystem
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Startups, Security Leadership, Educators
- **Mentions:** [OpenAI](../../organizations/openai.md), [Microsoft Azure](../../software/azure.yaml), [Visual Studio Code](../../software/vs-code.yaml), [GitHub Actions](../../software/github-actions.yaml), [Microsoft](../../organizations/microsoft.md)
