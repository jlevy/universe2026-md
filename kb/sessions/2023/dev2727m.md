# GitHub: The best developer experience built by developers, for developers

**Thu Nov 9 2023, 10:15 AM–10:55 AM PST** · [Main Stage](../../rooms/ybca-main-stage.yaml)

**Speakers:** [Mario Rodriguez](../../people/mario-rodriguez.md), [Naresh Choudhary](../../people/naresh-choudhary.md)

From the first line of code that was ever committed to build GitHub, our purpose has been to equip developers with the tools they need to do their best work on a platform purpose-built for them. In this talk Mario Rodriguez, VP of Product Management at GitHub, will be diving in and sharing all of the exciting new features across our platform that increase developer productivity, boost creative collaboration, and ensure that organizations have the features and functionality they need to innovate at scale. GitHub—the best developer experience built by developers, for developers.

- **Type:** Main Stage
- **Track:** Developer Experience
- **Level:** Level 100: Introductory
- **Topics:** Artificial Intelligence (AI), Continuous Integration + Continuous Deployment (CI/CD), DevOps, Software Engineering, Testing and related practices, Collaboration, Productivity
- **GitHub products:** Actions, Codespaces, Discussions, Enterprise/Admin, Extensibility/Ecosystem, Projects, Issues, Pages
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Startups, Security Leadership, Educators
