# Workshop: Accelerated innovation: coding practices for the modern developer

**Tue Nov 7 2023, 11:30 AM–1:00 PM PST** · [Hyatt - Gallery Ballroom II](../../rooms/hyatt-gallery-ballroom-ii.yaml)

**Speakers:** [Ken Muse](../../people/ken-muse.md) (facilitator), [William Salazar](../../people/william-salazar.md) (facilitator)

**Session must be added during registration in order to add to your schedule** Traditional development practices are not enough in today's business landscape. Developers must write software faster while continuously improving quality. In this practical hands-on session, attendees will create ready-to-run environments with GitHub Codespaces, improve code quality with GitHub Copilot, and use GitHub Actions and GitHub Advanced Security together to automate and secure their code.

- **Track:** AI, Developer Experience, Security
- **Level:** Level 100: Introductory
- **GitHub products:** Actions, Advanced Security, Codespaces, Copilot
- **Audience:** Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals
