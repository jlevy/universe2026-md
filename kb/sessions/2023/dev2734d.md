# From chaos to order: using repository rules to deliver code compliance at scale

**Wed Nov 8 2023, 3:00 PM–3:25 PM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Patrick Knight](../../people/patrick-knight.md)

Governing code in repos can be challenging and, across many repos, feels downright chaotic. Learn how repository rules can make the branches across your organization secure and compliant, allowing you to confidently meet your organization's standards quickly. You'll see how to protect a single repository and then scale that protection up to all production repositories in an organization. From the visibility of rules while pushing code, to new types of rules and the ease of management, everyone has something to take away.

- **Type:** Product Demo
- **Track:** Developer Experience
- **Level:** Level 200: Intermediate
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), DevOps, DevSecOps, Git and related code management techniques, Supply Chain Security
- **GitHub products:** Actions, Enterprise/Admin
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Security Professionals
