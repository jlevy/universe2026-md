# Revolutionizing IoT development with GitHub Actions and Arm virtual hardware

**Wed Nov 8 2023, 11:00 AM–11:25 AM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Eric Sondhi](../../people/eric-sondhi.md)

Developers creating Internet of Things software use a complex stack of software, running on a diverse range of Arm-based devices that often need to be custom built into their CI/CD platform. Come see a demonstration of the native integration of AVH and GitHub Actions (currently in private beta), along with real-world examples of incorporating Arm-based reference platforms—and common Arm-based devices like the Raspberry Pi—into GitHub Actions CI/CD workflows.

- **Type:** Product Demo
- **Track:** Developer Experience
- **Level:** Level 100: Introductory
- **Topics:** Artificial Intelligence (AI), Cloud, Continuous Integration + Continuous Deployment (CI/CD), Productivity
- **GitHub products:** Actions
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Startups
