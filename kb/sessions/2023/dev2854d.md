# Scaling DevSecOps in the Advanced Security Universe

**Wed Nov 8 2023, 2:30 PM–2:55 PM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [René van Osnabrugge](../../people/rene-van-osnabrugge.md), [Charlton Trezevant](../../people/charlton-trezevant.md), [Rob Bos](../../people/rob-bos.md)

In the fast-paced world of software development, security and compliance with DevSecOps practices is top of mind. We will embark on a journey to explore the intricate balance between rapid development, stringent security requirements, and regulatory compliance. Our expert speakers will demonstrate real-world strategies and cutting-edge tools that empower organizations to scale DevSecOps practices while maintaining robust security measures and staying compliant with industry standards. Learn about the journey that our enterprise customers have taken with us from our experts.

- **Type:** Product Demo
- **Track:** Developer Experience
- **Level:** Level 200: Intermediate
- **Topics:** Agile practices, Automated Infrastructure Deployment, Cloud, Continuous Integration + Continuous Deployment (CI/CD), DevOps, DevSecOps, Git and related code management techniques, Infrastructure as Code, Security, Vulnerability Detection, Productivity
- **GitHub products:** Actions, Advanced Security, Supply Chain Security, Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Security Professionals, Security Leadership, Educators
- **Mentions:** [GitHub Advanced Security](../../software/github-advanced-security.yaml)
