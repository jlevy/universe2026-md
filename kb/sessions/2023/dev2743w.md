# Workshop: Migrate your CI/CD Pipelines using GitHub Actions Importer

**Thu Nov 9 2023, 12:30 PM–2:00 PM PST** · [Hyatt - Gallery Ballroom II](../../rooms/hyatt-gallery-ballroom-ii.yaml)

**Speakers:** [Ari LiVigni](../../people/ari-livigni.md) (facilitator), [Sandra Parlant](../../people/sandra-parlant.md) (facilitator)

**Session must be added during registration in order to add to your schedule** In this workshop, we will walk through a high-level overview of GitHub Actions Importer and its capabilities. We'll then forecast resources for GitHub Actions based on current running workloads, and automate importing CI/CD pipelines to GitHub Actions from existing CI/CD systems like Jenkins, GitLab, Azure DevOps, Travis CI, and CircleCI. We will dive deeper into Jenkins as our workshop example.

- **Type:** Workshop
- **Track:** Developer Experience
- **Level:** Level 200: Intermediate
- **Topics:** Cloud, Continuous Integration + Continuous Deployment (CI/CD)
- **GitHub products:** Actions, Codespaces
- **Audience:** Enterprise - Developers, Open Source Developers or Maintainers
- **Mentions:** [GitHub Actions](../../software/github-actions.yaml), [Jenkins](../../software/jenkins.yaml), [GitLab](../../software/gitlab.yaml), [Azure DevOps](../../software/azure-devops.yaml), [CircleCI](../../software/circleci.yaml)
