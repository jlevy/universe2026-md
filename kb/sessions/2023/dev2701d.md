# Transforming your developer experience with GitHub Codespaces

**Thu Nov 9 2023, 1:00 PM–1:25 PM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Brian Beck](../../people/brian-beck.md), [Shivani Banerjee](../../people/shivani-banerjee.md)

Developers are looking for ways to explore APIs, build, and launch as quickly and effectively as possible. PayPal is using GitHub Codespaces to provide developers the ability to see their APIs in action and modify or enhance their code with a PayPal VS Code plugin, and clone the code to their own repo.
