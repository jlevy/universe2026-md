# How to solve for accessibility…without a lot of extra work

**Wed Nov 8 2023, 12:30 PM–12:55 PM PST** · [Demo Stage](../../rooms/ybca-demo-stage.yaml)

**Speakers:** [Kevin Berg](../../people/kevin-berg.md)

Developers want their projects to be accessible. But it’s tough to master yet another complex topic and still stay on track.  Fortunately, Evinced can help you immediately start delivering accessible code with tools that integrate directly into the things developers are already doing: coding, unit testing, and functional testing. 

In this demo, Kevin will cover two of Evinced's tools: Unit Tester, which runs powerful accessibility checks directly inside your IDE alongside your existing unit tests, and Code Assistant, which works with LLMs to reliably provide accessible code completions.
