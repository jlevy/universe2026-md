# How GitHub securely uses GitHub

**Thu Nov 9 2023, 1:30 PM–2:10 PM PST** · [Screening Room](../../rooms/ybca-screening-room.yaml)

**Speakers:** [Michael Recachinas](../../people/michael-recachinas.md), [John Ruiz](../../people/john-ruiz.md), [Joseph Katsioloudes](../../people/joseph-katsioloudes.md)

In this session, you'll gain practical insights to bolster the security of your GitHub instances as well as your software development lifecycle, ever the more important in today's constantly evolving digital landscape. 

We'll begin with an exploration of how we secure our supply chain — our code, dependencies, and CI/CD with GitHub Advanced Security. We'll discuss our internal fundamentals program and cover essential enterprise security topics, like secrets hygiene, organizational design, and managing external collaborators. You’ll also hear from our security team’s experts on how we configure, use, and govern our use of GitHub at GitHub.

- **Type:** General Session
- **Track:** Security
- **Level:** Level 200: Intermediate
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), Security, Supply Chain Security, Vulnerability Detection, Collaboration, Productivity
- **GitHub products:** Advanced Security
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Security Professionals, Security Leadership
- **Mentions:** [GitHub Advanced Security](../../software/github-advanced-security.yaml)
