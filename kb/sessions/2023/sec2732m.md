# Redefining the next decade of cybersecurity: AI-powered security built to empower developers

**Wed Nov 8 2023, 11:15 AM–11:45 AM PST** · [Main Stage](../../rooms/ybca-main-stage.yaml)

**Speakers:** [Asha Chakrabarty](../../people/asha-chakrabarty.md), [Mike Hanley](../../people/mike-hanley.md), [Robert Daugherty](../../people/robert-daugherty.md), [Brittany O'Shea](../../people/brittany-o-shea.md)

AI is ushering in a new era for security, presenting some of the most promising opportunities to secure code from the start. Join us as we explore GitHub Advanced Security’s mission in this new paradigm, and how AI-powered security solutions will position developers as leaders in a global security strategy. We’ll reflect on how GitHub helped make a positive impact in application security over the last year, shed light on what’s next, and explore the intricate dynamics at play as AI becomes a cornerstone feature in the industry. Together, we'll redefine the concept of shifting security left and shape the security landscape for the next decade.
