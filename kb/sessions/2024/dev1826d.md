# Contributing with confidence: Capital One's open source contribution workflows

**Tue Oct 29 2024, 10:30 AM–10:55 AM PDT** · [Demo Studio](../../rooms/demo-studio-gateway-pavilion.yaml)

**Speakers:** [eric sorenson](../../people/eric-sorenson.md), [Riley Kohler](../../people/riley-kohler.md)

Organizations in highly regulated industries face strict regulatory requirements—and though many are interested in contributing to open source projects, they often require a private review process. GitHub recently released an open source tool called the Private Mirrors App, which Capital One is incorporating into a new OSS contribution portal.

Join Eric Sorenson, senior product manager, and Riley Kohler, software engineer in the Open Source Programs Office (OSPO) at Capital One, to learn more about these tools and how to create an open source contribution workflow tailored to your organization's needs.

- **Level:** Level 100: Introductory
- **Topics:** Open Source, Collaboration, Community, Productivity

- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers
