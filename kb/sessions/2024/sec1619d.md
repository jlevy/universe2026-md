# Keep your secrets secret: How GitHub prevented 100K+ public leaks in 2024

**Tue Oct 29 2024, 11:30 AM–11:55 AM PDT** · [Demo Stage](../../rooms/demo-stage-gateway-pavilion.yaml)

**Speakers:** [Courtney Claessens](../../people/courtney-claessens.md)

Thousands of secrets are accidentally leaked in public repositories every day, leaving individuals and entire organizations exposed to malicious attacks, data loss, and damage to brand reputation. GitHub is working towards a world where these types of leaks wouldn't happen.
 
In this session with Courtney Claessens, senior product manager at GitHub, you'll hear about the efforts GitHub has taken to prevent more than 100,000 secrets from being leaked since the start of the calendar year—all without developer setup. Join Courtney to learn more about how this work increases the security of the open source community and your enterprise.

- **Level:** Level 100: Introductory
- **Topics:** Open Source, Security, Vulnerability Detection
- **GitHub products:** Advanced Security
- **Audience:** Open Source Developers or Maintainers, Security Professionals, Security Leadership
