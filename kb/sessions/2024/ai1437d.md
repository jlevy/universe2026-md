# How to unlock the secrets of your legacy code with GitHub Copilot

**Wed Oct 30 2024, 3:00 PM–3:25 PM PDT** · [Demo Stage](../../rooms/demo-stage-gateway-pavilion.yaml)

**Speakers:** [Sophine Clachar](../../people/sophine-clachar.md), [Yadhav Jayaraman](../../people/yadhav-jayaraman.md)

Transform your legacy code with the advanced capabilities of GitHub Copilot.  In this session, Sophine Clachar, senior data scientist at Microsoft, and Yadhav Jayaraman, staff service delivery engineer at GitHub, will guide you through leveraging GitHub Copilot Chat for in-depth codebase analysis. Plus, learn how to use Copilot Chat to get a high-level view of the logic and functionality used by Copilot, and how to use personas to tailor its output to various roles, from developers to business analysts.
