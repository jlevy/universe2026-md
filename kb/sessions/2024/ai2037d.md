# SonarQube, the perfect companion to GitHub Copilot

**Wed Oct 30 2024, 2:00 PM–2:25 PM PDT** · [Demo Studio](../../rooms/demo-studio-gateway-pavilion.yaml)

**Speakers:** [Colin Mueller](../../people/colin-mueller.md)

**Hosted by:** [Sonar](../../organizations/sonar.md)

Generative AI will continue to reshape how developers write and review code. This talk, presented by Sonar Community Manager, Colin Mueller, will explore how SonarQube’s integration with GitHub and GitHub Copilot empowers developers and organizations to confidently integrate AI into their coding process. We’ll cover the entire workflow, from the first line written in your IDE to production. Discover how GitHub Copilot, the world’s most widely adopted AI developer tool, and SonarQube, the industry standard for code quality and security, work together to boost developer productivity while ensuring code integrity in the age of AI-assisted programming.

- **Type:** Product Demo
- **Track:** AI
- **Level:** Level 100: Introductory
- **Topics:** AI, DevOps, Software Engineering, Testing and related practices, Productivity, Tech Debt
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml)
