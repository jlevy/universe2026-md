# Cleared for takeoff: Embracing open source within the enterprise

**Tue Oct 29 2024, 12:30 PM–1:10 PM PDT** · [Gallery 308](../../rooms/gallery-308-building-a.yaml)

**Speakers:** [Jeffrey Berthiaume](../../people/jeffrey-berthiaume.md)

Navigating the friendly skies of open source within an enterprise requires strategic alignment, internal buy-in, and a vibrant open source community. 

In this session, Jeffrey Berthiaume, senior innovator, Southwest Airlines, will share a step-by-step approach for transitioning internal projects to open source while fostering a culture of collaboration. You'll learn practical strategies for gaining executive support, overcoming legal challenges, and building a sustainable ecosystem that drives innovation.

- **Type:** Breakout Session
- **Track:** Developer Experience
- **Level:** Level 100: Introductory
- **Topics:** Agile practices, Automated Infrastructure Deployment, Continuous Integration + Continuous Deployment (CI/CD), Git and related code management techniques, Monitoring and Observability, Open Source, Security, Social Impact, Software Engineering, Collaboration, Community
- **GitHub products:** Actions, Enterprise/Admin, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers
- **Mentions:** [Southwest Airlines](../../organizations/southwest-airlines.md)
