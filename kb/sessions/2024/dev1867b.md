# From migration to mastery: Building an engineering stack with GitHub in six months

**Tue Oct 29 2024, 11:30 AM–12:10 PM PDT** · [Gallery 308](../../rooms/gallery-308-building-a.yaml)

**Speakers:** [Adam Gross](../../people/adam-gross.md), [Bhanu Prakash Vandana](../../people/bhanu-prakash-vandana.md)

It's not often that a 2000+ developer organization needs to build a new engineering stack within the span of six months. Adam Gross, senior staff engineer at Omnissa, and Bhanu Prakash Vandana, senior member of technical staff, Omnissa, share how Omnissa (the former End User Computing business unit at VMware) did exactly this. 

Join this session to hear how Omnissa built on top of GitHub. Adam and Bhanu Prakash will cover everything from the selection of GitHub to the migrations from Perforce, GitLab, and BitBucket Server, to self-hosted runners, adoption of GHAS, and OSS management using FOSSA. They will go through migration details and drill down into use cases where the GitHub platform made all the difference in improving developer productivity.

- **Type:** Breakout Session
- **Track:** Developer Experience, Security
- **Level:** Level 100: Introductory
- **Topics:** Agile practices, Cloud, Continuous Integration + Continuous Deployment (CI/CD), Git and related code management techniques, Open Source, Software Engineering, Collaboration, Productivity, Tech Debt
- **GitHub products:** Actions, Advanced Security, Extensibility/Ecosystem
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers
- **Mentions:** [Omnissa](../../organizations/omnissa.md), [VMware](../../organizations/vmware.md), [GitLab](../../software/gitlab.yaml), [GitHub Advanced Security](../../software/github-advanced-security.yaml)
