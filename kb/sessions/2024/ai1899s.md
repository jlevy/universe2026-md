# Beyond the IDE: Unlocking the full power of GitHub Copilot

**Tue Oct 29 2024, 1:30 PM–2:10 PM PDT** · [Sandbox Stage](../../rooms/sandbox-stage-general-s-residence.yaml)

**Speakers:** [Dave Burnison](../../people/dave-burnison.md) (facilitator), [Christina Warren](../../people/christina-warren.md) (facilitator)

GitHub Copilot isn’t just for your favorite code editor—it offers a range of capabilities that extend far beyond. In this session, Christina Warren, senior developer advocate at GitHub, and Dave Burnison, senior DevOps advocate at GitHub, will demonstrate how to leverage GitHub Copilot across various tools and workflows. Discover how to utilize GitHub Copilot Chat for web and mobile development, how to get the benefits of Copilot in your terminal, and how to use GitHub Copilot Workspace to streamline your process from ideation to deployment. They’ll also showcase how to address security issues with Copilot Autofix and explore extending Copilot via GitHub Copilot Extensions that are available in the marketplace or created custom to your organization.

Note: This stage has limited capacity and will seat attendees at a first come first serve basis.  Adding this session to your schedule does not reserve a seat.  Please attend early.

- **Track:** AI, Developer Experience
- **Level:** Level 200: Intermediate
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), DevOps, Pair Programming, Security, Testing and related practices, Vulnerability Detection, Productivity
- **GitHub products:** Advanced Security, Copilot, Extensibility/Ecosystem
- **Audience:** Enterprise - Developers, Open Source Developers or Maintainers
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml)
