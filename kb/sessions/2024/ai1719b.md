# Building agentic systems with VS Code extensibility and GitHub Copilot at Uber

**Wed Oct 30 2024, 12:30 PM–1:10 PM PDT** · [Cowell Theater](../../rooms/cowell-theater-gateway-pavilion.yaml)

**Speakers:** [Matas Rastenis](../../people/matas-rastenis.md), [Sourabh Shirhatti](../../people/sourabh-shirhatti.md)

Join Uber's Matas Rastenis, senior software engineer, and Sourabh Shirhatti, product manager, to discover how the company elevated GitHub Copilot into a dynamic partner in development using VS Code extensibility. This session will cover how Matas and Sourabh developed agentic systems that merge automation with human input, enhancing developer productivity, and reducing toil. You'll learn about the tools and strategies they've adopted to integrate AI more deeply into Uber's coding processes. This presentation will offer practical insights into extending AI capabilities in a large-scale tech setting.

- **Topics:** AI, Human Factors, Software Engineering, Testing and related practices, Collaboration, Productivity
