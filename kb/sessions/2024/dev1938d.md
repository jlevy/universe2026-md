# Zeiss's journey on GitHub Enterprise Cloud: From optical precision to digital excellence

**Tue Oct 29 2024, 3:30 PM–3:55 PM PDT** · [Demo Studio](../../rooms/demo-studio-gateway-pavilion.yaml)

**Speakers:** [Henrik Böttcher](../../people/henrik-bottcher.md)

Founded in 1846, Carl Zeiss AG (ZEISS) has seen many cycles of transformation over the years as it's become a global technology leader in the fields of optics and optoelectronics. This talk with Henrik Boettcher, tech lead of Development Platforms at ZEISS, will cover the company’s shift from a hardware-centric firm to a software-driven enterprise, highlighting ZEISS’ experience on GitHub Enterprise Cloud. He’ll discuss how ZEISS uses GitHub Enterprise Cloud to enhance developer collaboration, code quality, and security, as one of the first customers to adopt GitHub's new data residency feature. He’ll also detail migration strategies for moving from existing code management systems to GitHub, which has increased developer agility.
