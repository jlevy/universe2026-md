# Push past default mode: Using CodeQL with models and custom queries

**Wed Oct 30 2024, 12:30 PM–2:00 PM PDT** · [Workshops](../../rooms/workshops-general-s-residence.yaml)

**Speakers:** [Jeongsoo Lee](../../people/jeongsoo-lee.md) (facilitator), [Joshua Ku](../../people/joshua-ku.md) (facilitator)

CodeQL is GitHub's semantic code analysis engine, which ships with thousands of models for common libraries and frameworks. It also relies on models of your dependencies, including company- or application-specific dependencies.

Join this workshop with GitHub's Jeongsoo Lee, CodeQL analysis engineer, and Joshua Ku, service delivery engineer, to learn how to use the CodeQL model editor, a UI-driven solution for creating models as data, for both default and custom queries. Jeongsoo and Joshua will also show you how to mass deploy these models and help stay ahead of security vulnerabilities.
