# Simplifying collaboration across multiple organizations using GitHub Projects

**Wed Oct 30 2024, 2:00 PM–2:25 PM PDT** · [Demo Stage](../../rooms/demo-stage-gateway-pavilion.yaml)

**Speakers:** [Claire Stehley](../../people/claire-stehley.md), [Gabriel Marangoni Moita](../../people/gabriel-marangoni-moita.md)

GitHub Issues and GitHub Projects support engineers writing code and leaders collaborating at a large scale across organizations. Join Claire Stehley, staff technical program manager at GitHub, and Gabriel Marangoni Moita, product owner of GitHub at SAP, as they unpack the benefits of collaborative project management with clear and transparent communication. They'll walk through a GitHub and SAP partnership case study, showcasing how GitHub's native tooling fosters collaboration, enabling teams to work together as one. You'll learn more about the challenges faced, how they were resolved, and the successful engineering execution model GitHub uses to drive our partnerships.

- **Type:** Product Demo
- **Track:** Developer Experience
- **Level:** Level 200: Intermediate
- **Topics:** Agile practices, Git and related code management techniques, Human Factors, Collaboration, Productivity
- **GitHub products:** Actions, Enterprise/Admin, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership
- **Mentions:** [GitHub Issues and Projects](../../software/github-issues-projects.yaml), [SAP](../../organizations/sap.md)
