# See GitHub Copilot and VS Code in action

**Tue Oct 29 2024, 2:00 PM–2:25 PM PDT** · [Demo Studio](../../rooms/demo-studio-gateway-pavilion.yaml)

**Speakers:** [Harald Kirschner](../../people/harald-kirschner.md), [Christopher Harrison](../../people/christopher-harrison.md)

As developers, we're always seeking tools that reduce repetitive tasks and free our minds for more complex challenges. So, consider: how much of your coding workflow could be streamlined with AI? 

Join Harald Kirschner, VS Code team member at Microsoft, for a demo that explores the evolution of GitHub Copilot in VS Code, including newly released and preview features that push the boundaries of AI in everyday development tasks. Harold will take a tangible approach to uncovering the true impact Copilot has on daily coding, backed by insights from the team behind Copilot's development.

- **Type:** Product Demo
- **Track:** AI
- **Level:** Level 200: Intermediate
- **Topics:** AI, Data Science, Git and related code management techniques, Shell Programming (Bash, PowerShell, etc.), Software Engineering, Testing and related practices, Productivity, Tech Debt
- **GitHub products:** Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Startups, Educators
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml), [Visual Studio Code](../../software/vs-code.yaml), [Microsoft](../../organizations/microsoft.md)
