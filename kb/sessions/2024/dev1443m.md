# Introducing the next chapter for GitHub Enterprise

**Tue Oct 29 2024, 11:15 AM–11:45 AM PDT** · [Main Stage](../../rooms/main-stage-festival-pavilion.yaml)

**Speakers:** [Todd Manion](../../people/todd-manion.md), [Dr. Holger Kasinger](../../people/dr-holger-kasinger.md)

GitHub Enterprise was released as a "self-hosted GitHub for your company" back in 2011. Later, businesses had the option to continue self-hosting using GitHub Enterprise Server or adopt the GitHub Enterprise Cloud, hosted by GitHub. Over time, additional controls like Enterprise Managed Users, Repository Rules, and more cemented GitHub Enterprise as an industry standard for professional software development.

Yet how we got here is less exciting than what lies ahead as we bring a robust data residency offering to GitHub Enterprise Cloud. Join us for a preview of the future of GitHub Enterprise Cloud, now with data residency available for customers in the EU, and other regions to come.
