# DevOps and security: Frenemies turned BFFs

**Tue Oct 29 2024, 2:30 PM–3:10 PM PDT** · [Cowell Theater](../../rooms/cowell-theater-gateway-pavilion.yaml)

**Speakers:** [Brian Rossi](../../people/brian-rossi.md) (panelist), [Colin Dembovsky](../../people/colin-dembovsky.md) (moderator)

DevOps has shown the value of deploying frequent small batches, and how treating both features and defects as "work" leads to predictability and visibility. These same principles can and should be applied to application security.
 
In this fireside chat between Colin Dembovsky, principal solution engineer at GitHub, and Brian Rossi, director of DevOps and cybersecurity at Caterpillar, you'll hear about the cultural shift Caterpillar's teams are making, treating security issues as just another form of "work" that can be prioritized in the backlog. Brian will discuss how GitHub Advanced Security has accelerated cultural change at Caterpillar though deep, low-friction integration of AppSec into the daily developer workflow.

- **Track:** Developer Experience, Security
- **Level:** Level 200: Intermediate
- **Topics:** Agile practices, DevSecOps, Security, Supply Chain Security, Vulnerability Detection, Productivity, Tech Debt
- **GitHub products:** Advanced Security
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Security Professionals, Security Leadership
- **Mentions:** [Caterpillar](../../organizations/caterpillar.md), [GitHub Advanced Security](../../software/github-advanced-security.yaml)
