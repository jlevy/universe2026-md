# An inside look at how GitHub uses LLMs, fine-tuning, and prompt engineering in GitHub Copilot

**Wed Oct 30 2024, 3:30 PM–4:10 PM PDT** · [Cowell Theater](../../rooms/cowell-theater-gateway-pavilion.yaml)

**Speakers:** [Matthew Masarik](../../people/matthew-masarik.md) (moderator), [Mitch Naylor](../../people/mitch-naylor.md) (panelist), [Cooper Nederhood](../../people/cooper-nederhood.md) (panelist), [Joe Bourne](../../people/joe-bourne.md) (panelist)

GitHub Copilot was the first at-scale AI assistant for code completion in software development. Join our moderator, Matthew Masarik, director of applied science, and panelists, Cooper Nederhood, machine learning engineer, Joe Bourne, staff product manager, and Mitch Naylor, senior applied machine learning researcher, all from GitHub, to learn how our Applied Science team is enhancing the quality of Copilot's code completion. Together, they'll discuss how GitHub uses LLM fine-tuning, RAG, prompt engineering, and other techniques to increase accuracy and supercharge productivity.

- **GitHub products:** Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Startups, Educators
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml)
