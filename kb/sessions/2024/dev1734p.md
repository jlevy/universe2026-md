# Open source and accessibility: Empowering people with disabilities globally

**Wed Oct 30 2024, 12:30 PM–1:10 PM PDT** · [Gallery 308](../../rooms/gallery-308-building-a.yaml)

**Speakers:** [Ed Summers](../../people/ed-summers.md) (moderator), [Joe Devon](../../people/joe-devon.md) (panelist), [Josh Miele](../../people/josh-miele.md) (panelist), [Christine Mendoza](../../people/christine-mendoza.md) (panelist)

Open source has become an integral part of the software that much of humanity uses to live, work, learn, and play. However, it's frequently unclear whether open source helps or hinders access for those with disabilities. 

Join this panel discussion to learn more about the current state of open source accessibility, and how individual developers and open source communities can help accelerate access for people with disabilities globally.

- **Type:** Panel Discussion
- **Track:** Developer Experience
- **Level:** Level 100: Introductory
- **Topics:** Accessibility, Open Source, Social Impact, Community
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Startups, Educators
