# From data scientist to developer: How GlaxoSmithKline upskilled 1,300 GitHub beginners in one year

**Wed Oct 30 2024, 2:30 PM–3:10 PM PDT** · [Cowell Theater](../../rooms/cowell-theater-gateway-pavilion.yaml)

**Speakers:** [Eleanor Sparling](../../people/eleanor-sparling.md)

GlaxoSmithKline (GSK) set a groundbreaking precedent within the pharmaceutical industry by leveraging GitHub for clinical trial reporting. In this session, Eleanor Sparling, data scientist at GSK, will discuss how GSK tackled large-scale change and upskilling, and redefined workflows to capitalize on automation. Eleanor will also share the downstream effects on quality control and measures taken to ensure regulatory compliance.

- **Type:** Breakout Session
- **Track:** Developer Experience
- **Level:** Level 100: Introductory
- **Topics:** Agile practices, Data Science, Git and related code management techniques, Human Factors, Collaboration, Productivity
- **GitHub products:** Actions, Discussions, Education, Enterprise/Admin, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Startups, Educators
- **Mentions:** [GSK](../../organizations/gsk.md)
