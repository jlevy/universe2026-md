# Copilot Autofix: Shaping the future of secure coding practices

**Wed Oct 30 2024, 11:30 AM–12:10 PM PDT** · [Sandbox Stage](../../rooms/sandbox-stage-general-s-residence.yaml)

**Speakers:** [Arthur Neves](../../people/arthur-neves.md) (facilitator), [Pierre Tempel](../../people/pierre-tempel.md) (facilitator)

Discover how AI is transforming code security in this dynamic session on Copilot Autofix in GitHub Advanced Security (GHAS), facilitated by Arthur Neves, staff software engineer, and Pierre Tempel, staff product manager, at GitHub. Learn to detect and fix vulnerabilities in real time through pull requests, ensuring better code integrity before production. Additionally, explore how GitHub's newest tools can enhance your security posture and compliance, and join us to help lead the charge in advancing security with AI.
