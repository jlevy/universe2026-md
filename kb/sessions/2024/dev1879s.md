# No training required: Easy ML model deployment using Arm-based GitHub Runners

**Wed Oct 30 2024, 12:30 PM–1:10 PM PDT** · [Sandbox Stage](../../rooms/sandbox-stage-general-s-residence.yaml)

**Speakers:** [Jason Andrews](../../people/jason-andrews.md) (facilitator), [Pareena Verma](../../people/pareena-verma.md) (facilitator)

**Hosted by:** [Arm](../../organizations/arm.md)

In the dynamic landscape of machine learning operations (MLOps), streamlined workflows are essential for successful model deployment. This technical workshop facilitated by Arm's Jason Andrews, distinguished engineer, and Pareena Verma, principal solutions architect, focuses on leveraging Arm-based runners within GitHub Actions to create robust MLOps pipelines. This session is tailored for machine learning use cases and will explore how to deploy pre-trained and quantized Large Language Models (LLMs)—without the need for additional training.
