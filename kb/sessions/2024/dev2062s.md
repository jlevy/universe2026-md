# Shifting left together: JFrog and GitHub

**Tue Oct 29 2024, 12:30 PM–1:10 PM PDT** · [Sandbox Stage](../../rooms/sandbox-stage-general-s-residence.yaml)

**Speakers:** [Bill Manning](../../people/bill-manning.md) (facilitator)

**Hosted by:** [JFrog](../../organizations/jfrog.md)

JFrog and GitHub have combined forces to solve the ever-growing problem of managing the software development lifecycle (SDLC). By unifying the code-centric capabilities of GitHub and JFrog’s binary-centric platform, organizations can enhance and protect their business by providing efficiency, stability, visibility, and security from development to production. Join Bill Manning, senior solution architect at JFrog, to discover how to leverage this simple, integrated solution to produce more secure software—fast. 

Note: This stage has limited capacity and will seat attendees at a first come first serve basis.  Adding this session to your schedule does not reserve a seat.  Please attend early.

- **Type:** Sandbox Session
- **Level:** Level 200: Intermediate
- **Topics:** AI, Cloud, Continuous Integration + Continuous Deployment (CI/CD), Containerized Applications, DevOps, DevSecOps, Open Source, Security, Supply Chain Security, Software Engineering, Vulnerability Detection, Collaboration, Productivity
- **GitHub products:** Actions, Advanced Security, Supply Chain Security, Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Startups, Security Leadership
