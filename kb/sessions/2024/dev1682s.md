# Continuous deployments, the GitHub way

**Wed Oct 30 2024, 3:30 PM–4:10 PM PDT** · [Sandbox Stage](../../rooms/sandbox-stage-general-s-residence.yaml)

**Speakers:** [Turgay Akbas](../../people/turgay-akbas.md) (facilitator), [Igwe Kalu](../../people/igwe-kalu.md) (facilitator)

The continuous deployment concept has been around for a long time, and it's not uncommon to integrate with GitHub to accomplish CI/CD implementation goals. However, there's a way to do it simply and with security in mind, and GitHub's Senior Service Delivery Engineer, Igwe Kalu, and compeple AG's DevOps/Platform Engineer, Turgay Akbas, will show you how.

In this breakout session, Igwe and Turgay will define relatable bounding contexts in the CI/CD domain and show how to accurately associate respective contexts to fitting GitHub events, implement artifact attestation, and secure deployment to a CSP with OIDC. You'll learn how to integrate security and safeguard your implementation outcomes.

Note: This stage has limited capacity and will seat attendees at a first come first serve basis.  Adding this session to your schedule does not reserve a seat.  Please attend early.

- **Track:** AI, Developer Experience, Security
- **Level:** Level 300: Advanced
- **Topics:** Agile practices, AI, Automated Infrastructure Deployment, Continuous Integration + Continuous Deployment (CI/CD), DevOps, DevSecOps, Security, Supply Chain Security, Vulnerability Detection, Productivity
- **GitHub products:** Actions, Advanced Security, Supply Chain Security, Codespaces, Copilot, Discussions, Pages
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Startups, Security Leadership, Educators
