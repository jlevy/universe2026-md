# Let's build an app with GitHub Copilot in 40 minutes!

**Wed Oct 30 2024, 10:30 AM–11:10 AM PDT** · [Sandbox Stage](../../rooms/sandbox-stage-general-s-residence.yaml)

**Speakers:** [Ari LiVigni](../../people/ari-livigni.md) (facilitator), [Bryant Jimin Son](../../people/bryant-jimin-son.md) (facilitator)

Use GitHub Copilot as your AI pair programmer to develop a real app with little time and information. Together, you'll create a full stack of technologies for the infrastructure, frontend, and backend using the latest Copilot features.
