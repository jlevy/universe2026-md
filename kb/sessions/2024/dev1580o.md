# The sky’s the limit: Supercharge innovation through GitHub Certifications

**Tue Oct 29 2024, 11:45 AM–12:05 PM PDT** · [Universe Plaza](../../rooms/universe-plaza.yaml)

**Speakers:** [Christina Liberto](../../people/christina-liberto.md) (panelist), [Ali Condah](../../people/ali-condah.md) (moderator), [Jackie Mak](../../people/jackie-mak.md) (panelist)

Your GitHub adoption is underway — repos are migrated, code is flowing, and vulnerabilities are fixed. But have you truly set up your team for success? 

In this fireside chat with KPMG's Christina Liberto, Associate, Cyber Threat Management, and Jackie Mak, Consulting Manager, learn why it's worth getting certified in GitHub Foundations, Actions, Admin, GitHub Advanced Security, and Copilot.

Empower developers with practical strategies and tactics that can be put to immediate use, and learn how getting certified helps to quickly generate big wins and deliver on business outcomes.
