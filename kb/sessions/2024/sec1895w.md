# Enterprise code security 101: Getting started with GitHub Advanced Security

**Wed Oct 30 2024, 10:30 AM–12:00 PM PDT** · [Workshops](../../rooms/workshops-general-s-residence.yaml)

**Speakers:** [Cuno Reijman](../../people/cuno-reijman.md) (facilitator), [Daniel Meppiel](../../people/daniel-meppiel.md) (facilitator)

There are two primary ways a comprehensive software security solution like GitHub Advanced Security (GHAS) delivers value to your organization: first, by helping to stop new vulnerabilities and secrets from making their way into production and second, by helping you quickly fix existing security issues hidden within your production code.

Join GitHub's Cuno Reijman, customer success architect, and Daniel Meppiel, senior customer success architect, to learn how to get the maximum value from GHAS—quickly, and in a way that’s scalable for even the largest developer organizations, without compromising the developer experience.

- **Type:** Workshop
- **Track:** Security
- **Level:** Level 100: Introductory
- **Topics:** Agile practices, Continuous Integration + Continuous Deployment (CI/CD), DevSecOps, Human Factors, Security, Supply Chain Security, Social Impact, Software Engineering, Testing and related practices, Threat Modeling, Vulnerability Detection
- **GitHub products:** Actions, Advanced Security, Supply Chain Security, Enterprise/Admin
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Startups, Security Leadership, Educators
- **Mentions:** [GitHub Advanced Security](../../software/github-advanced-security.yaml)
