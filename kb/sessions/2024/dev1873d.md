# LaunchDarkly and GitHub team up for AI-powered feature management in your IDE

**Tue Oct 29 2024, 12:30 PM–12:55 PM PDT** · [Demo Stage](../../rooms/demo-stage-gateway-pavilion.yaml)

**Speakers:** [Chris Leon](../../people/chris-leon.md)

**Hosted by:** [LaunchDarkly](../../organizations/launchdarkly.md)

LaunchDarkly recently partnered with GitHub to improve the developer experience by bringing AI-powered feature management more directly into your IDE. In this session, Chris Leon, staff solutions engineer at LaunchDarkly, will show you how to automate the core actions of feature management so that you can control and de-risk releases directly from your IDE. 

Chris will cover how you can automate common actions in the flag lifecycle directly in VS Code, get LaunchDarkly documentation questions answered by GitHub Copilot, and use GitHub Actions to automatically populate code references in LaunchDarkly.

- **Type:** Product Demo
- **Track:** AI, Developer Experience, Security
- **Level:** Level 200: Intermediate
- **Topics:** Accessibility, Agile practices, AI, Automated Infrastructure Deployment, Continuous Integration + Continuous Deployment (CI/CD), Data Management, DevOps, DevSecOps, Software Engineering, Productivity
- **GitHub products:** Actions, Advanced Security, Copilot, Extensibility/Ecosystem
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers
- **Mentions:** [Visual Studio Code](../../software/vs-code.yaml), [GitHub Copilot](../../software/github-copilot.yaml), [GitHub Actions](../../software/github-actions.yaml)
