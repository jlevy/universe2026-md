# Getting seamless mobile development from code to app store like a pro

**Tue Oct 29 2024, 1:30 PM–1:55 PM PDT** · [Demo Studio](../../rooms/demo-studio-gateway-pavilion.yaml)

**Speakers:** [Jenn Robison](../../people/jenn-robison.md)

Create a seamless journey through mobile app development, from initial coding to your app store release. Learn how to address common challenges and streamline processes with GitHub Actions workflows, tailored to your needs. In this session, Jenn Robison, a principal software engineer, will showcase tools like Expo Application Services (EAS) for testing, debugging, and deployment, and Doppler for secrets management.

- **Track:** Developer Experience
- **Level:** Level 100: Introductory
- **Topics:** Agile practices, Continuous Integration + Continuous Deployment (CI/CD), DevOps, Software Engineering, Productivity
- **GitHub products:** Actions
- **Audience:** Enterprise - Developers, Open Source Developers or Maintainers, Startups
