# Go big! Efficiently deploy and customize security tooling at enterprise scale

**Wed Oct 30 2024, 10:30 AM–11:10 AM PDT** · [Gallery 308](../../rooms/gallery-308-building-a.yaml)

**Speakers:** [Eric Bickle](../../people/eric-bickle.md)

Whether you're a nimble team managing 30 repositories or an expansive enterprise with thousands, the rollout of new security tools can seem daunting. In this session, Eric Bickle, senior principal application security engineer at Asurion, will show you how easy it is to deploy and tune GitHub Advanced Security (GHAS) to your organization’s diverse needs. Eric will give you an in-depth look at how to deploy CodeQL at scale, respond to security alert dismissals, use Copilot Autofix to efficiently remediate existing code, and build a GitHub app for custom security workflows.

- **Track:** Security
- **Level:** Level 300: Advanced
- **Topics:** Security, Vulnerability Detection
- **GitHub products:** Advanced Security, Enterprise/Admin
- **Audience:** Security Professionals, Security Leadership
