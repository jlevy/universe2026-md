# Safe and secure: Using CodeQL to validate safety-related applications

**Tue Oct 29 2024, 4:30 PM–5:10 PM PDT** · [Sandbox Stage](../../rooms/sandbox-stage-general-s-residence.yaml)

**Speakers:** [Luke Cartey](../../people/luke-cartey.md) (facilitator)

The development of safety-related applications necessitates taking a rigorous approach to software security and quality during development. However, traditional tooling in this space can be difficult to deploy and integrate. In this sandbox session with Luke Cartey, director of Security Services at GitHub, you'll see how code scanning and CodeQL can be used to help seamlessly verify that applications are safe and secure throughout the development process. Luke will work through an open source example from the automotive industry, enabling CodeQL Coding Standards, GitHub's C/C++ safety-focused rule set, and show how it can satisfy the requirements of ISO26262.
