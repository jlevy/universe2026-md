# The latest and greatest ways to manage repositories at scale

**Wed Oct 30 2024, 3:30 PM–3:55 PM PDT** · [Demo Stage](../../rooms/demo-stage-gateway-pavilion.yaml)

**Speakers:** [Patrick Knight](../../people/patrick-knight.md), [Aaron Scofield](../../people/aaron-scofield.md)

Are you striving for consistent and efficient management across your GitHub organization’s repositories? Discover how our new enhancements can ease your approach. In this session, you’ll learn how to achieve naming consistency, manage repository visibility, and streamline administration across all or specific groups of repositories. With features that support both automation enthusiasts and those preferring a manual approach, we have a few new things to show you to help better manage your repositories at scale.

- **Type:** Product Demo
- **Track:** Developer Experience
- **Level:** Level 100: Introductory
- **Topics:** Agile practices, Automated Infrastructure Deployment, Git and related code management techniques, Security
- **GitHub products:** Enterprise/Admin
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Startups, Security Leadership
