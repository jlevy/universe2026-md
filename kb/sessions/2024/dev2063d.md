# The Frog and the Octocat: A software development love story

**Wed Oct 30 2024, 11:00 AM–11:25 AM PDT** · [Demo Stage](../../rooms/demo-stage-gateway-pavilion.yaml)

**Speakers:** [Yonatan Arbel](../../people/yonatan-arbel.md)

**Hosted by:** [JFrog](../../organizations/jfrog.md)

In fairytales, when the princess kisses the frog, it generally turns out well. We like to think the Frog and Mona the Octocat live happily ever after, too. That's because the partnership between JFrog and GitHub helps keep companies safe as they rely on the software supply chain and their proprietary code. Together, our solutions create a unified software development experience to streamline application security throughout the software delivery lifecycle (SDLC). In this session with Yonatan Arbel, developer advocate at JFrog, you'll see how you can achieve advanced application security coverage from code to runtime in a single pane of glass. You'll also discover how AI enables users to ask questions about package versions, usage, and security, and see how GitHub Copilot Autofix can leverage JFrog security results to help remediate your code.

- **Level:** Level 200: Intermediate
- **Topics:** Cloud, Continuous Integration + Continuous Deployment (CI/CD), Containerized Applications, DevOps, DevSecOps, Open Source, Security, Supply Chain Security, Software Engineering, Vulnerability Detection, Collaboration, Productivity
- **GitHub products:** Actions, Advanced Security, Supply Chain Security, Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Security Professionals, Startups, Security Leadership
