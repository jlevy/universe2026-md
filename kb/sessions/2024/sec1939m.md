# Securely building GitHub on GitHub

**Wed Oct 30 2024, 12:45 PM–1:25 PM PDT** · [Main Stage](../../rooms/main-stage-festival-pavilion.yaml)

**Speakers:** [Mike Hanley](../../people/mike-hanley.md), [Xavier René-Corail](../../people/xavier-rene-corail.md), [Whitney Imura](../../people/whitney-imura.md), [Michael Recachinas](../../people/michael-recachinas.md)

As the world’s leading Copilot-powered developer platform, GitHub embeds security directly into the developer workflow so that the platform trusted by millions of developers provides enhanced security at every step.

This extends to how we adopt security controls to protect the GitHub platform and the novel ways we are building AI-native security experiences to achieve greater security outcomes. In this session, we’ll show you how we’re building GitHub more securely to support the world’s developers.
