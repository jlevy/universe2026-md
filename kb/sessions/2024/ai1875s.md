# Develop and test your APIs faster with GitHub Copilot and Postbot

**Wed Oct 30 2024, 2:30 PM–3:10 PM PDT** · [Sandbox Stage](../../rooms/sandbox-stage-general-s-residence.yaml)

**Speakers:** [Pooja Mistry](../../people/pooja-mistry.md) (facilitator)

**Hosted by:** [Postman](../../organizations/postman.md)

Join us as we delve into the powerful synergy between GitHub Copilot and Postman’s Postbot, a Copilot extension that transforms API development and testing. By leveraging AI-driven code assistance from Copilot alongside Postman’s advanced testing capabilities, you’ll learn how to significantly speed up the creation and testing of APIs.

By the end of the session facilitated by Pooja Mistry, developer advocate at Postman, you’ll have a solid understanding of how to integrate these tools to streamline your API development workflow, enhance productivity, and ensure the delivery of high-quality APIs.
