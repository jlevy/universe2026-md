# Better together: Tips, tricks, and lessons learned from pairing GitHub and Azure

**Wed Oct 30 2024, 2:30 PM–3:10 PM PDT** · [Discussions Lounge](../../rooms/discussions-lounge-firehouse.yaml)

**Speakers:** [Suzanne Daniels](../../people/suzanne-daniels.md) (facilitator), [David Sanchez](../../people/david-sanchez.md) (facilitator), [Krystal Folkes Brown](../../people/krystal-folkes-brown.md) (facilitator)

In this interactive session, Microsoft's David Sanchez, Krystal Folkes, and Suzanne Daniels will dive into the seamless integration between GitHub and Microsoft Azure and reveal how these technologies work together to enhance software development. You'll discover proven tips and tricks learned through real-world stories and practical scenarios. Presenters will also address common challenges, share strategies, and discuss lessons learned. Engage in a collaborative discussion to gain actionable insights and elevate your projects.

- **Track:** AI, Developer Experience
- **Level:** Level 200: Intermediate

- **GitHub products:** Actions, Advanced Security, Supply Chain Security, Codespaces, Copilot, Discussions, Enterprise/Admin, Pages, Projects and Issues
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Security Professionals, Security Leadership
