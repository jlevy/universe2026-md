# Hey, where's my deployment? Simplify CD with Octopus and GitHub Copilot

**Wed Oct 30 2024, 12:30 PM–12:55 PM PDT** · [Demo Stage](../../rooms/demo-stage-gateway-pavilion.yaml)

**Speakers:** [Matthew Casperson](../../people/matthew-casperson.md)

**Hosted by:** [Octopus Deploy](../../organizations/octopus-deploy.md)

If you've ever committed a code change and had things not go quite right, join Matthew Casperson, principal solutions engineer at Octopus Deploy, to explore how the Octopus Deploy extension for GitHub Copilot reshapes the developer experience—reducing friction and eliminating context switching. Discover how developers can interact with Octopus directly within Copilot to automate routine tasks so they can focus on writing great code. By the end of this session, you'll walk away with a foundation for streamlining workflows, boosting efficiency, and elevating the developer experience across your org with the Octopus extension.

- **Level:** Level 200: Intermediate
- **Topics:** AI, Continuous Integration + Continuous Deployment (CI/CD), DevOps, Kubernetes, Software Engineering, Collaboration, Productivity
- **GitHub products:** Copilot, Sponsors
- **Audience:** Enterprise - Developers
