# Accelerating cloud-to-edge development flows with GitHub Copilot and GitHub Actions

**Tue Oct 29 2024, 3:45 PM–4:25 PM PDT** · [Main Stage](../../rooms/main-stage-festival-pavilion.yaml)

**Speakers:** [Alex Spinelli](../../people/alex-spinelli.md), [Eric Sondhi](../../people/eric-sondhi.md), [Jason Andrews](../../people/jason-andrews.md), [Pareena Verma](../../people/pareena-verma.md)

**Hosted by:** [Arm](../../organizations/arm.md)

Developers love how GitHub and Arm have partnered to integrate Arm tools, platforms, and workflows into GitHub Actions to accelerate software development. Attend this session with Alex Spinelli, vice president of Developer Technology, Eric Sondhi, Sr. Manager, IoT Line of Business, Jason Andrews, Distinguished Engineer, and Pareena Verma, Principal Solutions Architect at Arm, to see how Arm is extending across the GitHub platform to make you even more impactful and productive when building, testing, and deploying your software on Arm.
 
Alex and the team will also share how Arm has enabled the GitHub development community with faster, more efficient build systems for AI, MLOps, and CI/CD, powered by native Arm Runners in Actions. You'll see how to easily migrate to Arm and flexibly support multiple architectures in your Actions pipelines.

- **Type:** Main Stage
- **Track:** AI, Developer Experience
- **Level:** Level 200: Intermediate
- **Topics:** AI, Cloud, Continuous Integration + Continuous Deployment (CI/CD), DevOps, Machine Learning, Software Engineering
- **GitHub products:** Actions, Copilot, Enterprise/Admin
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Startups
- **Mentions:** [GitHub Copilot](../../software/github-copilot.yaml), [GitHub Actions](../../software/github-actions.yaml)
