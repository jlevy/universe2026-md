# Is AI fundamentally changing the way that we write code?

**Wed Oct 30 2024, 11:30 AM–12:10 PM PDT** · [Discussions Lounge](../../rooms/discussions-lounge-firehouse.yaml)

**Speakers:** [Burke Holland](../../people/burke-holland.md) (facilitator), [Harald Kirschner](../../people/harald-kirschner.md) (facilitator), [Allison Weins](../../people/allison-weins.md) (facilitator)

Join fellow developers in this collaborative session where you'll explore the real-world impact of AI tools like GitHub Copilot on coding workflows. 

Facilitators, Burke Holland, principal cloud advocate at Microsoft, Harald Kirschner, a VS Code team member at Microsoft, and Allison Weins, staff product manager - GitHub Copilot at GitHub, will dive into practical applications—from automating tasks to balancing AI suggestions with human oversight. As a group, you'll address common challenges like ensuring code quality, managing AI integration, and navigating complex problem-solving with these tools. Use this session as a space to exchange experiences, discuss concerns, and discover practical solutions for AI-driven development.

- **Topics:** AI, Software Engineering, Collaboration, Productivity, Tech Debt
- **GitHub products:** Copilot
