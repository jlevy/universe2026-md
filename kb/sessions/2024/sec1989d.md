# Scaling security: Deploying GitHub Advanced Security in your organization

**Tue Oct 29 2024, 3:00 PM–3:25 PM PDT** · [Demo Stage](../../rooms/demo-stage-gateway-pavilion.yaml)

**Speakers:** [Catalina Berretta](../../people/catalina-berretta.md)

As organizations grow, ensuring consistent and effective security practices across multiple repositories and teams becomes increasingly complex. GitHub’s code security configurations help address this challenge by enabling organizations to easily deploy and manage security tools at scale. In this session, Catu Berretta, product designer II at GitHub, will walk you through the step-by-step process of setting up and customizing these configurations. See firsthand how to integrate these tools into your workflows and ways to effectively scale security practices across your organization to help protect your organization from secret leaks and vulnerabilities.

- **Track:** Security
- **Level:** Level 100: Introductory
- **Topics:** Security, Supply Chain Security
- **GitHub products:** Advanced Security, Supply Chain Security
- **Audience:** Open Source Developers or Maintainers, Security Professionals, Startups, Security Leadership
