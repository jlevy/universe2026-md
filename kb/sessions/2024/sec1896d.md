# Automated governance: An evidence-based approach to asset inventory

**Tue Oct 29 2024, 4:30 PM–4:55 PM PDT** · [Demo Studio](../../rooms/demo-studio-gateway-pavilion.yaml)

**Speakers:** [Michael Edenzon](../../people/michael-edenzon.md)

Software asset inventory is an often overlooked, but critical component of automating policy enforcement in the DevOps pipeline. Poor inventory paired with broad policies can subject developers to having unnecessary or inaccurate requirements added to their workflows.

In this session, Michael Edenzon, CEO and co-founder of Fianu, will outline the common gaps in existing software inventories and provide simple, actionable steps that DevOps engineers can take to establish an evidence-based software asset inventory. You'll learn how the powerful combo of Fianu and GitHub can unblock even the most entrenched manual processes.

- **Type:** Product Demo
- **Track:** Developer Experience, Security
- **Level:** Level 300: Advanced
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), DevOps, DevSecOps, Monitoring and Observability, Supply Chain Security, Testing and related practices, Vulnerability Detection
- **GitHub products:** Actions, Advanced Security, Supply Chain Security
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Security Professionals
- **Mentions:** [Fianu](../../organizations/fianu.md)
