# Releasing faster and with more confidence using GitHub Actions and GitHub Copilot

**Wed Oct 30 2024, 10:30 AM–10:55 AM PDT** · [Demo Stage](../../rooms/demo-stage-gateway-pavilion.yaml)

**Speakers:** [Chris Griffing](../../people/chris-griffing.md)

Discover how GitKraken leverages the powerful combination of GitHub Actions and GitHub Copilot to streamline the software development lifecycle (SDLC). Hear from Chris Griffing, developer advocate at GitKraken, about the company's org structure, migration from Jenkins, and the key GitHub Actions they utilize. In this session, Chris will explore a real-world case study that showcases GitHub Copilot's impact on efficiency and bug detection for a DevEx platform used by 30 million developers. Gain insights to help enhance productivity, collaboration, and improve code quality in your own projects with automation and AI.

- **Type:** Product Demo
- **Track:** AI, Developer Experience
- **Level:** Level 200: Intermediate
- **Topics:** AI, Automated Infrastructure Deployment, Continuous Integration + Continuous Deployment (CI/CD)
- **GitHub products:** Actions, Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developers, Open Source Developers or Maintainers, Startups
- **Mentions:** [GitHub Actions](../../software/github-actions.yaml), [GitHub Copilot](../../software/github-copilot.yaml), [GitKraken](../../organizations/gitkraken.md), [Jenkins](../../software/jenkins.yaml)
