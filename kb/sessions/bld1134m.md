# The view from the labs: What's next for AI-assisted development

**Thu Oct 29 2026, 9:00 AM–9:30 AM PDT** · [Main Stage](../rooms/main-stage-festival-pavilion.yaml)

**Speakers:** [Rohan Varma](../people/rohan-varma.md) (panelist), [April Leonard](../people/april-leonard.md) (moderator), [Richard Seroter](../people/richard-seroter.md) (panelist), [Angela Jiang](../people/angela-jiang.md) (panelist)

The people building frontier AI models see early signals about where capabilities are heading and which skills and workflows are about to matter more or require a shift. This interactive panel brings together leaders from the major frontier model labs (Anthropic, OpenAI, and Google Cloud) that power GitHub Copilot for the conversation developers actually want: a candid, forward-looking discussion about what the next two years of AI-assisted development look like, and what that means for the people in the room.

- **Type:** Main Stage
- **Track:** Build software, not code, Lead through what's next
- **Level:** Level 200: Intermediate
- **Topics:** Open source, AI: Agents, AI: MCP and other integrations, AI: Models
- **GitHub products:** Supply Chain Security, GitHub Copilot, GitHub Secret Protection, GitHub Code Security
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer, Open Source Developer or Maintainer, Security Professional, Startups, Security Leadership
- **Mentions:** [Anthropic](../organizations/anthropic.md), [OpenAI](../organizations/openai.md), [Google](../organizations/google.md), [GitHub Copilot](../software/github-copilot.yaml)
