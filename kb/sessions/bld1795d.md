# Day 1 deploy, day 2 recovery: AI agents across the full delivery lifecycle (Sponsored)

**Wed Oct 28 2026, 2:30 PM–2:45 PM PDT** · [Silent Disco Demos](../rooms/silent-disco-demos-festival-pavilion.yaml)

**Speakers:** [James Chatmas](../people/james-chatmas.md)

**Hosted by:** [Octopus Deploy](../organizations/octopus-deploy.md)

Imagine a developer just joined a large, regulated enterprise. Their application is in GitHub, but they've never used the company's deployment platform.

In this live demo, James Chatmas follows that developer from Day 1 to Day 2. First, an AI agent helps create a governed Octopus deployment process and complete the first successful deployment. Then, when a later deployment fails, the Octopus Intelligence Agent diagnoses the issue, runs the approved remediation, and redeploys, all from GitHub. You'll see how human approvals, runbooks, and deployment controls let teams automate recovery without sacrificing governance.

- **Type:** Product Demo
- **Track:** Build software, not code
- **Level:** Level 200: Intermediate
- **Topics:** Continuous Integration + Continuous Deployment (CI/CD), DevOps and DevSecOps, Platform engineering, Governance and compliance, AI: Agents, AI: MCP and other integrations
- **GitHub products:** Actions, GitHub Copilot
- **Audience:** Enterprise - Engineering Leadership, Enterprise - Developer
