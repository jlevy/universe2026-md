# Janani Chandiran

[PayPal](../organizations/paypal.md)

Listed for GitHub Universe 2025 as Sr. Manager Product Management, PayPal.

- **GitHub Universe 2025:** speaker (confirmed)

Janani is a senior product manager at PayPal, where she leads developer-focused AI tools that serve over 35 million merchants worldwide. With extensive experience in API product management and governance, she currently spearheads initiatives including PayPal's VS Code extension and AI Assistant. 

Prior to PayPal, Janani served as API product manager at U.S. Bank, where she authored REST API standards and established comprehensive API lifecycle management frameworks. She has a proven track record of transforming complex technical challenges into streamlined developer experiences, including API transformation tools that modernize legacy systems. Janani holds a master's degree in Telecommunications and Networking from the University of Pennsylvania and is passionate about empowering developers through innovative tooling and seamless integration experiences.
