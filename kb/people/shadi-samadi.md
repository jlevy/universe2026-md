# Shadi Samadi

Staff Service Delivery Engineer, GitHub

- **GitHub Universe 2023:** speaker (confirmed)

Shadi is a staff engineer focused on delivering GitHub Advanced Security solutions to organizations worldwide. Her work involves implementing GitHub’s code analysis and security tooling, helping enterprise teams integrate secure development practices at scale. With deep expertise in the CodeQL analysis engine, Shadi develops custom queries to uncover vulnerabilities and improve the security posture of large, complex codebases.
