# Kaush Ganguly

Sr. Cloud Solution Architect - AI Apps, [Microsoft](../organizations/microsoft.md)

- **GitHub Universe 2026:** speaker (confirmed)

Kaush is a Senior Cloud Solution Architect at Microsoft who helps organizations move from experimenting with GitHub Copilot to scaling AI-assisted development securely and responsibly. He leads application modernization and migration initiatives across Australia and New Zealand, working with digital-native and enterprise teams on complex codebases using GitHub Copilot, GitHub Actions, GitHub Advanced Security, Azure AI, and cloud-native delivery patterns. With a background in developer advocacy, Kaush has delivered more than 50 talks, workshops, and hands-on labs for developers, architects, security practitioners, and engineering leaders globally. Active on GitHub since 2013, he brings a practical, field-tested perspective on agentic modernization, DevSecOps, and cloud-native architecture. Outside work, he reimagines classic rock songs on guitar.
