# Ben Rodes

[Microsoft](../organizations/microsoft.md)

Listed for GitHub Universe 2025 as Principal Security Engineer, Microsoft.

- **GitHub Universe 2025:** speaker (confirmed)

Dr. Benjamin Rodes is a principal security engineer at Microsoft on the code analysis platform team. He and his team apply static analyses, specifically CodeQL, to Microsoft products and services to establish compliance with internal Microsoft standards, and to detect vulnerabilities both before deployment and in response to security incidents. Dr. Rodes also leads internal research and development of the application of CodeQL for detecting uses of quantum-vulnerable algorithms and is a member of the NIST NCCOE consortium on defining detection tools and guidelines for quantum-vulnerable cryptographic algorithms. 

Dr. Rodes’ academic and professional career has focused on automated vulnerability detection and exploit generation, binary reverse engineering, binary modifications for enhanced security, rigorous assurance cases, and the application of formal methods.
