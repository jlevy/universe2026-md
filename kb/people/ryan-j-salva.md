# Ryan J. Salva

VP, Product Management, GitHub

- **GitHub Universe 2023:** speaker (confirmed)

Ryan is VP of Product at GitHub where for the last three years he has looked after GitHub’s AI strategy. For those who don’t follow the Generative AI space closely, GitHub launched one of the very first large-scale services to use large language models, GitHub Copilot. Ryan came to GitHub from Microsoft where he looked after a massive developer business, Azure DevOps, as well as Microsoft’s internal developer infrastructure. With 24 years in software development in both startups and enterprise, there’s hardly a part of the software development lifecycle Ryan hasn’t touched.
