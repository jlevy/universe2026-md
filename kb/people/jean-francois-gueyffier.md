# Jean-François Gueyffier

DevOps Cloud Engineer, Air France KLM

- **GitHub Universe 2023:** speaker (confirmed)

Jean-François has been working in the IT industry since 2000, starting with a network and system background. Since 2006, he has worked as a Web Infrastructure Engineer at Air France-KLM.

As of January 2022, Jean-François joined the Cloud Infrastructure Competency Center as a DevOps cloud engineer. In this role, his responsibilities include supporting the integration to Azure Cloud as part of Air France-KLM's IT transformation. The technology he works with includes Terraform, GitHub, Azure Cloud, PowerShell, Azure CLI, and others.
