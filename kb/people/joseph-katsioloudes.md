# Joseph Katsioloudes

Senior Developer Advocate, GitHub

- **GitHub Universe 2025:** speaker (confirmed)
- **GitHub Universe 2024:** speaker (confirmed)
- **GitHub Universe 2023:** speaker (confirmed)

Joseph is a security specialist who empowers developers to ship secure software through his research and education work at the GitHub Security Lab. His recent contributions include video content—collectively viewed over 1.2 million times—packed with practical security tips, as well as the free game gh.io/securecodegame, which helps software developers build security skills. In its first year, the game attracted more than 10,000 players worldwide.

As a speaker who has delivered 62 talks across 25 countries in the past three and a half years, Joseph captivates audiences with his insights and dynamic presentation style.
