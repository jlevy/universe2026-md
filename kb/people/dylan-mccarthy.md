# Dylan McCarthy

Principal Consultant, [Nexwave](../organizations/nexwave.md)

Dylan is a Principal Solution Consultant at Versent, working at the intersection of modernization, developer experience, and AI-assisted software development. He helps organizations adopt tools like GitHub Copilot in ways that improve how developers actually work, balancing productivity, cost, and quality.
