# Savannah Ostrowski

Senior Product Manager, Microsoft

- **GitHub Universe 2023:** speaker (confirmed)

Savannah Ostrowski is a senior product manager at Microsoft, focused on Azure cloud native developer tools and experience. She is the product lead for the open source Azure Developer CLI (azd) and its ecosystem. Previously, she was the product manager for the Pylance language server (which powers the Python editing experience in Visual Studio Code, Codespaces, Visual Studio and more!) and focused on improving Python developer experience in tools like Visual Studio Code, Visual Studio and on Azure. She's passionate about open source software, DevOps, and developer experience.
