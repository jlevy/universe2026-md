# Xavier René-Corail

Sr. Dir, Security Research, [GitHub](../organizations/github.md)

- **GitHub Universe 2026:** speaker (confirmed)
- **GitHub Universe 2024:** speaker (confirmed)
- **GitHub Universe 2023:** speaker (confirmed)

Xavier is the Senior Director of the GitHub Security Lab, where he works to inspire the open source community, security researchers, and developers to secure open source software through better security practices. Before GitHub, Xavier led developer advocacy at Semmle (acquired by GitHub in 2019) and was an engineering manager at Murex, where he drove adoption of development best practices including Extreme Programming, Test-Driven Development, Agile, DevOps, and secure coding.
