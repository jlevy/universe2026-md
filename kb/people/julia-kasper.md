# Julia Kasper

Product Manager, [Microsoft](../organizations/microsoft.md)

- **GitHub Universe 2026:** speaker (confirmed)

Julie is a Product Manager working on Visual Studio Code and GitHub Copilot, focused on helping developers build with confidence and joy. She has always loved the editor space because it's where small ideas turn into reality: every day, millions of developers open VS Code to explore ideas, debug problems, and ship software. Today, her work centers on LLM releases in VS Code and Copilot Chat, bringing AI capabilities to developers in a practical, high-quality way and improving how they use AI in their daily workflows. She also focuses on offline evaluations for VS Code, building evals to measure quality, catch regressions, and validate real-world usefulness before changes or new models ship.
