# Camila Maia

Co-founder, [Cumbuca Dev](../organizations/cumbuca-dev.md)

- **GitHub Universe 2026:** speaker (confirmed)

Camila is a software engineer with over 16 years of experience specializing in developer experience and open source, with a strong background in backend development using Python and Ruby.

She is internationally recognized for her contributions to the open source ecosystem, including being featured by the Open Source Initiative, highlighted in the maintaine.rs 2025 edition, recognized by GitHub as an official Open Source Maintainer in Brazil, selected for the GitHub Secure Open Source Fund program with ScanAPI, and credited with creating the first GitHub Sponsors account in Brazil.

Camila is the co-founder of Cumbuca Dev, an open source community focused on making open source more accessible and inclusive, especially for underrepresented groups in Brazil.

She is passionate about empowering developers, improving tooling, and building sustainable open source communities, and believes that people always come before technology.
