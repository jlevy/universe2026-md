# Martin Woodward

VP, Developer Relations, [GitHub](../organizations/github.md)

- **GitHub Universe 2026:** speaker (confirmed)
- **GitHub Universe 2025:** speaker (confirmed)
- **GitHub Universe 2023:** speaker (confirmed)

Martin is the VP of developer relations at GitHub, helping developers and open source communities create delightful things. Prior to that role, he was part of the Microsoft team that built tooling for DevOps teams inside and outside the company, transforming how Microsoft builds software—by reshaping how it collaborates with open source communities and engages with developers.

Martin was the original creator of the Microsoft organization on GitHub. He also helped set up the .NET Foundation and brought in companies like Amazon, Google, Samsung, and Red Hat to help drive its future direction. Martin joined Microsoft when it acquired his five-person startup—built on an Eclipse-based Java platform—and later served on the acquisition team when Microsoft acquired GitHub.
