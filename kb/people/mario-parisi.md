# Mario Parisi

[General Motors](../organizations/general-motors.md)

Listed for GitHub Universe 2025 as Manager, Software Development, General Motors.

- **GitHub Universe 2025:** speaker (confirmed)

With 25+ years in software design and development, Mario is a software development manager at General Motors, leading a high-performing team in building scalable, innovative solutions. He has driven the strategic adoption of GitHub Enterprise to modernize practices across source control, DevOps, and collaboration. His leadership has enabled agile workflows, protected branches, rigorous pull request reviews, and automated CI/CD pipelines powered by GitHub Actions and other enterprise tools. He’s also established UAT-driven QA, monitoring, and feedback loops that foster transparency and accountability. 

Beyond technical delivery, he defines project goals, timelines, and success metrics that align with GM’s broader business objectives. A dedicated mentor, Mario cultivates a learning culture supported by GitHub features like Discussions and wikis — empowering his team to stay agile, innovative, and engaged.
