# Kyle Daigle

- **GitHub Universe 2023:** speaker (confirmed)

A developer since age 12, Kyle has always been drawn to people, code and what happens when the two converge. Today, as GitHub’s Chief Operating Officer, he orchestrates this at scale, bringing together 3,000+ Hubbers and 150M+ developers to build the future of software, together. Since joining GitHub in 2013, Kyle shipped code for GitHub webhooks, the API, and GitHub Actions before leading acquisitions like Semmle and npm. Now, leading teams from Developer Relations to Global Brand & Marketing, Kyle shapes how GitHub runs, how it stays developer first, and how it brings its launches to the world. Prior to GitHub, Kyle focused on developer challenges as an engineering and product leader in startups and FinTech. When he’s not working on GitHub, you’ll find him building smart home automation with Home Assistant and focusing on tech accessibility with local nonprofits.
