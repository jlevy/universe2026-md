# Eddie Aftandilian

Principal Researcher, GitHub

- **GitHub Universe 2025:** speaker (confirmed)
- **GitHub Universe 2023:** speaker (confirmed)

Eddie is a principal researcher in GitHub Next, GitHub’s research and prototyping team.  He is one of the creators of GitHub Copilot, and led the Copilot model team from the prototype phase to general availability.  After rotating off Copilot, he has worked on additional AI-for-code projects such as Copilot for Docs, Copilot Workspace, and Continuous AI.  Before joining GitHub, Eddie worked on Java tools at Google and continues to serve on the Java “Project Amber” expert group.  He is passionate about creating tools that empower developers to be happier and more productive.  Outside of work, Eddie enjoys running and spending time with his family.
